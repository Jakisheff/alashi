ALASHI · Политэкономическая аренаДеньги в игре: alashi · 1M = 1 000 000

Правила стола

За столом 2-6 живых фракций. Каждая вносит по 10M в банк. На старте у каждой 0 alashi, 0 товара и 1 влияние. Партия длится шесть раундов.

01 · Рынок

Выберите одну операцию: продать, купить или пасовать. Решения раскрываются в случайном порядке. Таблица цен за лот: 12, 10, 9, 8, 7, 6, 5, 4, 3, 3, 2, 2, 2, 1, 1, 1M. Продажа двигает общий счётчик вперёд, покупка назад, минимум до нуля. Цена покупки определяется текущим счётчиком. Затем счётчик уменьшается. Налог удерживается только с продаж. При нехватке кассы во время вскрытия покупка отменяется целиком. Каждый раунд счётчик обнуляется.

02 · Действие

Одно действие: произвести 2 товара; купить у осла 1 товар за 1M; дать взятку; пасовать. Взятка передаёт всю сумму другой фракции. Каждые полные 5M дают отправителю +1 влияние: 9M дают +1, 10M дают +2. Тратить можно только доступную при выборе кассу.

03 · Закон

После действий президентом становится фракция с максимальным влиянием; при равенстве первая вошедшая. Вес тайного голоса равен влиянию. Закон принят при строгом перевесе «за» над «против» и без вето. Воздержание не добавляет веса. Только президент может запечатать вето вместе с голосом. До вскрытия содержание решения скрыто.

В колоде восемь карт, без повторов до её исчерпания. Затем колода перемешивается заново.

  • Status quo: без нового эффекта.
  • Налог 10% и налог 20%: заменяют ставку налога с продаж.
  • Субсидия производства: производство даёт 3 товара.
  • Субсидия бедным: беднейшая по кассе фракция получает +1 влияние.
  • Субсидия богатым: богатейшая по кассе фракция получает +1 влияние.
  • Эмбарго: цены следующего раунда −2M, минимум 1M.
  • Бум: цены следующего раунда +2M.

Налог сохраняется до следующего принятого налогового закона. Любой принятый закон заменяет субсидию производства и сдвиг цен своими значениями: ноль, если карта их не даёт. Сдвиг цен действует один раунд, эффекты не складываются. Отклонённый закон ничего не меняет. При равенстве касс субсидию получает фракция, вошедшая раньше.

Расчёт

После шестого раунда места определяются кассой, при равенстве порядком входа. Из банка вычитается рейк 5%. Доли мест: 50, 30, 15, 5. Берутся первые доли по числу фракций, максимум четыре; знаменатель равен их сумме. Выплаты округляются вниз до alashi, весь остаток получает первое место. С пятого места выплата ноль. Победитель определяется по кассе плюс выплата.

Налоги учитываются отдельно от банка взносов. Расчёты рынка виртуальные. Решения скрываются на экране передачи устройства. Игра живёт только в памяти вкладки: перезагрузка сбросит партию. Открывайте ход, когда остальные отвернулись.
