# Шесть агентов в одном кадре

Запрос владельца от 06.09: сначала показать общую карту для объяснения игры, затем оставить шесть карт одновременно. Музыка: NO CHURCH IN THE WILD - 8 BIT REMIX - N.O.R.M.

Наблюдаемое поведение: первые 10 секунд занимает общая 3D-карта с названиями зданий. Затем появляется сетка 3×2: Aitore, Aikorkem, Aisultan, Botagul, Aibot, Zhambyl. Каждая камера следит за своим агентом на общей арене. Имя и результат действия остаются в его панели.

С 10-й по 18-ю секунду видны шесть кошельков и подтверждения входа локального валидатора, слот 351. Параллельная отправка этих транзакций подтверждена отдельным протоколом STUDIO_LOCAL_PROOF_20260906.json. Общий записываемый аккаунт Game не позволяет считать это доказательством параллельного исполнения инструкций.

С 18-й по 108-ю секунду воспроизводится журнал HTTP-партии №21. Все панели используют одну фазу и общую шкалу времени. Паузы сжаты внутри фазы. Положение фигур иллюстрирует действие, координат движения в исходном журнале нет. Это повтор, новые агенты при просмотре не запускаются.

Последние 12 секунд показывают кассу и выплаты этой HTTP-партии. Они не обозначены ончейн-выплатами. Движок игры и расчёт денег не менялись.

Проверка до экспорта: все 101 попытка действия представлены; данные каждой совпадают с архивом, включая отказы. Найдены моменты движения всех шести агентов одновременно. Ошибок JavaScript и внешних запросов при открытии HTML нет. Проверка готового MP4 записывается в PARALLEL_VIDEO_20260906.json.

Музыкальный источник: https://www.youtube.com/watch?v=8UZNRIAD2mk, автор NORMALLY RETRO. Использованы первые 120 секунд записи с нормализацией громкости и затуханием. Исходник музыки хранится вне репозитория. Контрольная сумма включена в отчёт экспорта.

Сборка:

```sh
yt-dlp --no-playlist -f bestaudio -o '/private/tmp/alashi-norm.%(ext)s' 'https://www.youtube.com/watch?v=8UZNRIAD2mk'
python3 tools/build_parallel.py
node tools/parallel_video.cjs /Users/amir/.npm/_npx/e41f203b7505f1fb/node_modules/playwright --preview
node tools/parallel_video.cjs /Users/amir/.npm/_npx/e41f203b7505f1fb/node_modules/playwright
node tools/parallel_video.cjs /Users/amir/.npm/_npx/e41f203b7505f1fb/node_modules/playwright --verify
```

Результат: Desktop/alashi-parallel.mp4, H.264, 1920×1080, 24 кадра/с, AAC. Desktop/alashi-parallel-player.html открывает его с кнопками воспроизведения и перемотки. HTML-сцена app/alashi-parallel-demo.html работает отдельно, без звуковой дорожки.
