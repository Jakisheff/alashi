# Product choices left open

The current behavior is `source_defined`; proposed changes are `hypothesis`. These options address findings 3, 5 and 8 in the [audit](../IMPLICIT_STATE_MACHINES_20261107.md). No option is selected or implemented in this repair. Costs below describe affected contracts and checks, not measured delivery estimates.

| Finding | Keep current behavior as an explicit exception | Add a guard | Add cancellation or expiry |
|---|---|---|---|
| 3. Roof after an action | Document that another Action, such as Produce/Shuttle, may precede roof when its other conditions hold, while roof spends the action allowance for subsequent actions. Cost: preserve and explain the order dependence; acceptance cases must cover both orders. | Reject roof when the faction has already acted in this stamp. Cost: changes strategy legality; align the shared rules, client error handling and replay-equivalence tests for both execution modes. | Cancellation is a separate feature, not a remedy for the missing action guard. It needs a policy for paid protection, refunds and protection already used. Cost: new game semantics and state transitions; clearing the action stamp alone would allow extra actions. |
| 5. Empty forecast round | Declare that opening a round commits the comparison to waiting for at least one forecast. Cost: an unanswered roster can block the comparison indefinitely; UI must say so before opening. | Require participant opt-in before opening, or keep invitations in a nonblocking draft. Cost: new admission state/API/UI; opt-in still cannot guarantee a later answer or recover an already open empty round. | Allow the owner to cancel an empty round, or expire it at a defined deadline. Cost: persisted terminal status, owner authorization, late-response/race behavior, comparison-start policy and audit history; decide whether a new round may replace it. |
| 8. Full barter pool | Keep all eight slots occupied by outstanding offers until accepted, including across rounds; goods are not reserved. Cost: a full pool of stale offers can disable new offers; document this market outcome. | Per-maker quotas limit concentration; reserving goods can keep a seller's commitments backed. Cost: quotas do not recover a full pool, while reservation changes spendable inventory and requires release rules. Neither guarantees a buyer can or will pay. | Maker cancellation or expiry releases slots. Cost: authorize cancellation, define acceptance races and persistence across rounds, update clients and onchain instructions, and prove simulation/program replay equivalence. Expiry needs a time/round rule. |

The roof guard is a choice about the action allowance. Forecast and barter cancellation are choices about how commitments end. A guard that only prevents some new entries does not repair an already blocked round or full offer pool.
