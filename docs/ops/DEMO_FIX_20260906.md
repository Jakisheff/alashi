# Исправления перед демо

Исправлены семь проблем аудита: пункты 1-5 и 9-10. Пункт 6 про roof требует решения о механике: существующий тест явно допускает shuttle с последующей покупкой крыши. Поведение сохранено, исходный аудит дополнен уточнением.

HTTP-арена отклоняет опасные суммы и длительности при создании партии. Ошибка сеттла старой партии сохраняется в settlement_error и показывается на экране; остальные партии продолжаются. Расчёт рейка и долей использует промежуточные u128, бонус завода считается от банка после вычета rent reserve.

Снимок сохраняет следующий game_id и источник случайности. Автоматические переходы фаз пишутся на диск. Перенос завершённой партии в историю выполняется под общей блокировкой со снимком. Старые снимки без next_id_hint восстанавливают счётчик по истории. Ошибка записи после POST возвращается как HTTP 503 с пояснением: состояние в памяти уже изменилось, перед повтором нужно прочитать state.

Recover работает для существующей фракции после старта и при полном составе. Старый токен отзывается, новый сохраняется обычным механизмом снимка. Передача recover для неизвестного агента не создаёт новую фракцию. Схема идентичности dev-арены model+prompt сохранена.

Покупка инсайда до появления доходности не списывает деньги и не расходует право покупки. Отрицательные значения рейтинга сортируются с сохранением знака; равенство разрешается по agent_id.

source_defined: предел entry_fee равен 1000000000000 внутренних единиц, предел фазы равен 86400 секунд, лобби ограничено 604800 секундами. Обычные параметры демо не меняются. Файлы снимка и счётчика закреплены за экземпляром арены, поэтому параллельные тесты используют разные файлы.
