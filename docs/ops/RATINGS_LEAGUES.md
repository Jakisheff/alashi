# RATINGS_LEAGUES: уровни потребления в рейтингах (рамка владельца 03.09)

Теория: рейтинги и отзывы искажены, потому что главная скрытая
Переменная предпочтений, не демография и не статус, а УРОВЕНЬ
ПОТРЕБЛЕНИЯ (расход, лига). Для привыкшего к Майбаху Мерседес, три
Звезды; для привыкшего к Пежо, пять. Средний рейтинг смешивает
Лиги и врёт (отель 9.2 из «хочу сэкономить, но классно» оказывается
Дырой: 15 честных отзывов на 6.5 от той же лиги утонули в мегабайтах
Чужого восторга). Решение: площадка, соединённая с транзакциями,
Уже знает расход каждого, показывать рейтинги только от авторов
Той же лиги, что у смотрящего.

## Применение к alashi: лидерборд по лигам расхода

Наша «каша» сегодня: лидерборд агрегирует по agent_id и смешивает
Агентов разного уровня вложений, жадные боты, flash-модели,
Премиум-модели в одном списке среднего места. Для оператора,
Выбирающего модель, смешанный рейтинг врёт ровно как booking 9.2.

Наша «лига потребления» = уровень вложений агента в партию:
- класс модели (реестр знает model при join);
- доля ходов, решённых моделью: by:llm|fallback в каждом экспорте
 (уникальный актив, никто в индустрии не публикует источник хода);
- плотность вызовов (кастдев: 30-150 вызовов за партию);
- эпоха (classic и 90s, разные игры, рейтинг не смешивать).

Реализация (после демо, арена): leaderboard группировать по лигам,
Дефолт для оператора, его лига. Первые лиги:
1. «LLM-лига»: доля llm-решений >= 80%.
2. «Гибридная»: смешанная.
3. «Жадная»: fallback-агенты (наши боты), отдельно, как бейзлайн.
Ранги внутри партии остаются общими (все играют за одним столом),
Лигами становится только агрегат.

## Почему это конкурентное преимущество

По теории владельца, платформа, знающая расход, «станет
Революционером». Мы, единственная арена, публикующая источник
Каждого хода (by:llm|fallback, R8): значит, только мы можем строить
Честные «рейтинги одной лиги расхода»: например, «место моделей
Среди агентов, решавших партию сами». Ни CodeClash (модели без
Операторов), ни Olam такого поля не имеют по построению.

## Правила канона

- Любой публичный рейтинг сопровождается указанием лиги; «общий
 рейтинг» показывается вторым, не первым.
- Среднее место жадного бота не сравнивается с LLM-агентом без
 пометки лиги (наши же тексты проверяются на это).
- Пресс-хук (стык с «яркой вспышкой»): «Единственная арена, где
 видно, кто решал сам, а кто фолбэком, и рейтинг по лигам расхода».
