# Видео партии №21 для показа жюри

Владелец сообщил, что в предыдущем ролике невозможно разобрать активного участника и направление его действия. Тот ролик воспроизводил тестовую партию №31 с географическими названиями фракций. Для новой записи выбран сохранённый экспорт настоящей партии №21: data/live/party21_90s_export.json.

Состав партии: Aitore / Aikorkem / Aisultan / Botagul / Aibot / Zhambyl. Экспорт содержит 101 попытку хода; 97 приняты сервером. Четыре отказа также включены в повтор. Названия участников не подменяются.

## Видеоподача

- Имя активного агента показано шрифтом 72 px в кадре 1920×1080. На карте имя повторяется у его фракции.
- Активная фракция выделена контуром. Толстая стрелка соединяет её с местом действия; по стрелке движется маркер с первой буквой имени. Другие фракции приглушены.
- Справа видны место назначения и название действия. Результат операции отделён от её параметров. Касса показана шрифтом 48 px, товар 40 px.
- Попытка, отклонённая сервером, имеет явную подпись с причиной отказа. Сама стрелка обозначает намерение выполнить действие, а не подтверждение успеха.
- Итоги голосований вынесены на отдельные карточки. Финальная таблица занимает весь кадр.

Маршруты являются пояснением действий из журнала. Пространственное перемещение не добавляет стоимость, время или новые правила Alashi. Производство показано через условный узел завода; он не означает общий склад фракций.

## Данные и проверка

Observed: встроенный в app/alashi-party21-replay.html экспорт структурно совпадает с исходным JSON. Проверка охватывает все записи действий и финальные значения. Отдельный прогон JavaScript подтвердил, что 101 попытка появляется ровно один раз в исходном порядке; вместе с вступлением и итоговыми карточками получилось 109 сцен. Размеры промежуточной кассы и товара берутся из cash_after и goods_after. Повтор не рассчитывает экономику заново. Итоговая таблица использует серверный ранг и выплаты; отображение денег округлено до 0,001M.

Партия относится к эпохе 90-х. Выплата Zhambyl включает ренту лицензии и бонус завода. Твёрдая валюта хранится в экспорте отдельно от обычной кассы. В ролике не подставлены рейк и выплаты классической партии.

Метка происхождения каждого хода взята из поля by. Резервный алгоритм обозначен прямо; неизвестный источник не называется LLM. Надпись «Повтор по журналу» остаётся в кадре.

Проверены кадры продажи и голосования, а также отказ и финальная таблица. Отдельно просмотрен кадр шириной 960 px. Это проверка уменьшенного изображения, не испытание на физическом проекторе.

Самооценка по восьми пунктам refactoring-ui: предыдущая подача 6/10, новая 9/10. Исправлены визуальная иерархия, выделение значений и плотность экрана. Остался пункт строгой шкалы отступов: геометрия карты использует дополнительные размеры. Оценка субъективная, не результат пользовательского теста.

## Воспроизведение

app/alashi-party21-replay.html открывается локально без сети. Есть пауза, переходы по ходам и выбор скорости. Видеофайл сохраняется отдельно на рабочем столе владельца.

```
node tools/jury_video.cjs /путь/к/playwright /путь/к/alashi-jury-party21.mp4
```

Флаг --preview выполняет проверку архива и создаёт контрольные кадры без записи ролика. Флаг --verify проверяет декодирование готового MP4 в Chrome. Исходный серверный движок и живой зрительский интерфейс этой задачей не изменены.

Observed, 06.09.2026: готовый MP4 имеет длительность 392,00 секунды (6:32), разрешение 1920×1080, размер 40 121 725 байт. Chrome декодировал кадры в разных частях ролика. Длительность записи больше монтажной шкалы из-за времени захвата кадров. Контрольные суммы сохранены в JURY_VIDEO_20260906.json.
