# Презентация демо-дня 06.09

Владелец подтвердил регламент: 3 минуты презентации и 2 минуты демо. Основная версия содержит семь слайдов. Два дополнительных слайда предназначены для вопросов.

Тайминг речи по основным слайдам: 20, 25, 30, 0, 35, 35, 35 секунд. На четвёртом слайде запускается двухминутное видео. Всего 300 секунд.

Форматы: редактируемый PowerPoint с видео внутри файла, PDF для резервного показа и HTML с локальным видео. Комплект на ноутбуке: Desktop/Alashi Presentation. Тексты выступления находятся в docs/DEMO_TALK_20260906.md и заметках PowerPoint.

Числа сверены до сборки и внесены в docs/NUMBERS.md: 18 отслеживаемых экспортов; в партии №21 шесть агентов, 101 попытка действия, 97 принятых; отдельный локальный ончейн-прогон содержит 129 подписанных транзакций и шесть join в одном слоте. Происхождение ходов в HTTP-журнале заявлено клиентами. Эти данные не представлены как измерение нагрузки mainnet.

Из старой презентации убраны неподтверждённые рыночные цифры и устаревшее число тестов. Утверждения об уникальности рынка не вынесены на слайды. Заголовок сохраняет идею из POSITIONING: агенты выбирают действующие правила. Выбор происходит из заданной колоды.

Архитектурное объяснение параллельности сверено с официальным описанием Sealevel: https://solana.com/fr/news/sealevel---parallel-processing-thousands-of-smart-contracts. Одновременная отправка входов не названа доказательством параллельного исполнения записей в общий аккаунт.

Художественный кадр победы Aitore не используется как результат эксперимента. В заметках для вопросов указано происхождение кадра и действительный результат исходного экспорта.

Редакторская оценка по made-to-stick: старая версия 6/10, новая 9/10. Это самооценка текста, а не результат теста на аудитории. Новая оценка: простота 9, неожиданность 8, конкретность 9, проверяемость 9, эмоциональный интерес 8, история 7. Самый слабый пункт: история отдельного агента. Следующее улучшение после внешней партии: добавить проверенный пример изменения его стратегии. В текущей версии его заменяет наглядный сценарий изменения налога, обозначенный в речи как пример механики.

Сборка:

```sh
/private/tmp/alashi-deck-env/bin/python tools/deck_demo_build.py
node tools/deck_demo_browser.cjs /Users/amir/.npm/_npx/e41f203b7505f1fb/node_modules/playwright
```

Для сборки PPTX нужны python-pptx и Pillow. Браузерную часть проверяет локальный Playwright. Просмотр готового HTML не требует установки пакетов. Шрифт Jura приложен к комплекту и установлен на ноутбуке для PowerPoint.

Проверки: валидность XML в PPTX, девять слайдов, 86 редактируемых текстовых блоков, заметки на каждом слайде, побайтовое совпадение встроенного видео с финальным MP4. Браузерный протокол docs/out/deck_check.json фиксирует переполнение текста, запуск видео и работу без внешних запросов. Навигация проверяется на клавиатуре и кнопками, масштабирование на нескольких размерах окна. Воспроизведение встроенного ролика в самом приложении PowerPoint отдельно не проверялось.
