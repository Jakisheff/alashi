# Двухминутный cyberpunk-ролик Alashi

Ролик построен из интерфейса Alashi и данных проекта. Стоковых кадров нет. Чёрный фон, неоновые акценты синего и фуксии; суммы выделены кислотно-зелёным. Шрифт Jura встроен с лицензией OFL. Технические данные показаны моноширинным шрифтом. Крупные имена и маршруты из предыдущей версии сохранены.

## Монтажная шкала

| Секунды | Блок | Источник |
|---|---|---|
| 0-12 | Хук, имена шести агентов | Экспорт партии №21 |
| 12-24 | Почему Solana: подпись, Game PDA, расчёт | Программа Alashi |
| 24-48 | Шесть последовательных входов, по 4 секунды | Локальный Solana-валидатор |
| 48-92 | Одиннадцать реальных действий шести агентов | HTTP-партия №21 |
| 92-116 | Подтверждённая выплата с полным хэшем | Локальный Solana-валидатор |
| 116-120 | Название и адрес проекта | Репозиторий Alashi |

На границах блоков применяется короткий glitch в узких полосах. Появление хэша сопровождается декодированием символов и сканирующей линией. Подпись сети остаётся в кадре. Блок транзакций имеет обозначение LOCAL VALIDATOR; у геймплея указана HTTP ARENA / PARTY 21. Запись не называется прямой трансляцией.

По обратной связи владельца прежняя фоновая музыка удалена. Остались короткие звуки подтверждения на 24,8 / 28,8 / 32,8 / 36,8 / 40,8 / 44,8 / 92,8 секунды. Они совпадают с завершением декодирования сигнатуры. При записи аудио и видео используют одни часы AudioContext.

Порядок входов: Aitore → Aikorkem → Aisultan → Botagul → Aibot → Zhambyl. На экране крупное имя, полный кошелёк и собственная сигнатура участника. Нижняя полоса показывает очередь и завершённые входы. Каждый вход длится 4 секунды внутри прежнего блока 24-48 секунд.

## Происхождение транзакций

Для доказательства исполнения запущен отдельный solana-test-validator на порту 28999 с собранной программой target/deploy/alashi.so. Выполнен технический прогон классической партии на шести временных кошельках. Реальных средств и основного кошелька владельца прогон не использовал. После сохранения квитанций валидатор остановлен.

Observed: все 129 подписей проверены, ошибок исполнения нет. Проверка tools/cyber_proof_test.py сверяет подписи через solders по каноническим байтам сообщений. Для каждого входа проверяется один подписант, совпадение его кошелька с участником и имя в данных инструкции join. Первый участник создаёт игру, остальные входят без его подписи.

Observed расчёта: банк 60 000 000 lamports, выплаты по местам 28 500 000 / 17 100 000 / 8 550 000 / 2 850 000 lamports; последние два места без выплаты. Рейк 3 000 000 lamports. Это отдельная проверка контракта. Её выплаты не приписываются HTTP-партии №21 и не выдаются за переводы в публичной сети.

## Воспроизводимость

- tools/cyber_local_proof.py выполняет локальный прогон и сохраняет RPC-квитанции.
- docs/ops/CYBER_LOCAL_PROOF_20260906.json содержит публичные квитанции и контрольную сумму программы.
- tools/cyber_proof_test.py проверяет подписи, единственного подписанта входа и расчёт.
- tools/build_cyber.py собирает app/alashi-cyber-demo.html из исходной карты с оверлеем и встроенными данными.
- tools/cyber_overlay.js задаёт монтаж и синтез звука.
- tools/cyber_video.cjs записывает MP4. Флаг --preview создаёт контрольные кадры; --verify проверяет готовое видео и наличие декодированного аудио.

Ключи временных кошельков не сохранялись. Данные шести агентов взяты из data/live/party21_90s_export.json; выбранные действия идут в исходном порядке. Названия участников сохранены. Скрипт проверяет наличие всех шести имён и соответствие встроенных квитанций оригиналам.

Проверка монтажа создаёт кадры каждого входа и сверяет их данные с RPC-квитанциями. Проверка готового MP4 декодирует каждый вход; отдельно проверяет геймплей и финал. Физический проектор не проверялся.
