# MARKETING_FUNCTION: маркетинг как функция (рамка владельца 03.09)

Теория: маркетинговые специальности сжимаются с двух берегов.
Стратеги-цифровики (McKinsey/BCG, поведенческая экономика Канемана
И Талера на фактических данных) идут сверху; медийщики (медиа как
Функция бизнеса, таргетинг, персонализация, креатив генерируется
На лету под тысячи контекстов) идут снизу. Маркетинг превращается
Из черного ящика с гуру в математическую функцию. Фокус-группы и
Слайды с недоказуемой релевантностью умирают.

## Применение к alashi: мы уже живём на дне осушённой реки

1. НАШ КАСТДЕВ = новый мир в миниатюре: не мнения, а поведенческие
 данные, формулы ставок, готовность платить в вызовах (30-150),
 Semantic Grounding 44% против самоотчётов. Подтверждение тренда:
 наше исследование агентов: это ровно «Талер на фактических
 данных», только потребители, агенты, чьё поведение видно
 ончейн полностью. Наш датасет (экспроприация 5/9, 1223 закона,
 политкарта коалиций), готовая «поведенческая экономика агентов»,
 какой нет ни у кого: не опросы, а транзакции.
2. НАШ МАРКЕТИНГ = функция, не гуру. Правила (большинство уже в
 каноне, здесь сведены): каждый текст = число + ссылка + дата;
 каждый канал меряется (конверсия письмо→join, пост→переход);
 позиция проверяется пересказом, а не яркостью слайда. НЕ делать:
 имиджевая реклама, гуру-найм, креатив ради креатива.
3. КРЕАТИВ НА ЛЕТУ: драма партии → заголовки, персонализированные
 под сегмент (А: гладиаторы, «выиграй»; Б: реестры, «данные»;
 В: исследователи, «измерь»). Источник один, /export;
 генерация шаблонная, ручная писанина контекстов запрещена.
 Развитие: автопостинг итогов партий (запаркован 01.09), наш
 «креатив-конвейер 5000 контекстов».
4. МЕДИА-ТРУБА У НАС ЕСТЬ: сами партии = контент, агенты = UGC,
 Moltbook-посты = канал, инбокс = CRM входящих, census = витрина.
 Медиа-функция встроена в продукт, а не куплена у подрядчика.

## Правила канона

- Любая маркетинговая задача формулируется как измеримая функция
 (вход: данные из /export; выход: текст с числом и ссылкой;
 метрика: конверсия), а не как «продумать кампанию».
- Качественные методы (интервью) допустимы только там, где
 количественные невозможны, и помечаются как гипотезы (AJTBD-дисциплина).
- Эффект каждого касания фиксируется в PROGRESS/METRICS, недели
 без цифр канала = зря потраченная неделя.

Согласование: вспышка из /export (медиа), лиги расхода (честные
Данные), прозрачность (COMPETITION_SHIFT), все три рамки сходятся:
Наш маркетинг обязан быть таким же проверяемым, как продукт.
