# Дисциплина вывода MCP: маркер полноты против тихой обрезки харнессов

Дата: 26.11.2026. Повод: аудит поверхностей, через которые агент видит
игру, против измеренных лимитов агентских харнессов.

## Замеренные факты

1. Лимиты харнессов (разбор трёх харнессов по исходникам и бинарнику,
   09.11.2026, rwilinski.ai/posts/harness-teardown/):
   Claude Code меняет MCP-результат больше 50 000 символов на файл
   с превью ~2 КБ (предупреждение с 10K токенов, кап 25K токенов);
   Codex капит вывод инструментов на 10K токенов (голова+хвост);
   pi — последние 50 КБ / 2 000 строк для bash. Вывод: большой
   инструментный вывод агент видит обрезанным, часто без объявления.
2. Продакшен-замер (26.11): завершённая партия №1 (2 фракции,
   33 действия) — `/game/1/state` даёт 16 779 байт компактного JSON;
   прежний MCP-вывод pretty-print раздувал его до 30 054 байт (×1,79).
   Живой `/state` ограничен конструкцией: RECENT_ACTIONS_LIMIT=12,
   MAX_PHASE_LOG=512 (arena/src/api.rs:55) плюс окно
   recent_actions_range с first/last/retained seq — усечение
   заявляется в самом ответе.
3. Dialogue-API уже отдавал метки полноты страницы (has_more,
   next_cursor, latest_seq — chain_dialogue.rs), но MCP-инструмент
   watch жестко звал after=0: агент видел «есть ещё» и не мог
   взять следующую страницу.
4. Худший случай не измерен: завершённая партия на 6 фракций.
   Оценка ~×2,5-3 от двухфракционной (≈40-50 КБ компактно) —
   на границе файла-подмены Claude Code; честно помечено
   как unmeasured.

## Изменение (mcp.mjs, mcp.test.mjs)

- Вывод инструментов — однострочный JSON (убран ×1,79 pretty-накладной).
- Первый ключ каждого ответа — `mcp_payload: {bytes, complete, note}`:
  bytes = длина полного payload после маркера; complete=false возможно
  только если сам сервер усёк вывод (сегодня не делает — контракт
  зафиксирован на будущее). Маркер стоит в голове, поэтому survives
  любой головной превью харнесса: агент, увидевший 2 КБ, знает
  полный размер и может потребовать остальное.
- watch-инструмент получил параметр `after` (курсор диалога);
  пагинация замыкается: has_more → next_cursor → after.
- Сервер 0.1.0 → 0.2.0.

## Проверка

`node --test mcp.test.mjs` — зелёный (5 новых утверждений: однострочность,
маркер первым ключом, complete=true, bytes целое > 0, тело ошибки
сохранено). Полный набор `npm test` в tools/agent-bootstrap:
144 теста, 142 pass, 2 skip (Rust-воркер недоступен), 0 fail.

## Открытые хвосты

- Замер 6-фракционной завершённой партии (когда появится; world-100
  данные вне репо).
- Головной превью Claude Code режет по байтам головы: маркер
  гарантированно виден, но граница payload/маркер не проверялась
  на живом Claude Code (offline-тест покрывает только формат).
