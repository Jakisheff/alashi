# Анти-дистилляция, срез 1: инвентаризация утечки и канарейка в /state

Дата: 27.11.2026. Исполнитель: агент (opencode). Задача из промпта
anti-distillation (фаза 0.2 и срез канареек). Оправдание метода:
Oren et al. 2023, arXiv:2310.17623 (канареечные пробы с точным
p-value); BigCode The Stack (канарейки в корпусе).

Итог инвентаризации: скрейп-поверхность сайта сегодня ничтожна
(~21 КБ игровых данных). Реальный публичный актив для тренировки —
датасет world-100-grid (Kaggle #1451) и карточки CC0 в репо, а не
живой API. Вывод: канарейки обязательны в ДАТАСЕТЕ (следующий срез),
в API они стоят дёшево и закрывают рост поверхности.

## Три атаки (разграничение, фаза 0.1)

- (а) корпусная контаминация: претрейн увидел арена-данные
  (сейчас маловероятен: поверхность мала);
- (б) целенаправленный тюнинг на публичной лиге через API
  (станет реален с ростом арены);
- (в) адаптивный гейминг — зона анти-читов арены, вне этого среза.

Актив переопределён: защищается различительная способность на свежих
мирах, не сами данные.

## Канарейка (код)

- `canary_of(game_id, party_no)` в arena/src/api.rs: доменный
  SHA256 «alashi-canary-v1» по канону партии; формат
  `alashi:canary:<64 hex>`; стабильна до/после рестарта (выводится
  из game_id+party_no, не из памяти).
- Поле `canary` в публичном state_json рядом с party_no; описание
  маршрута в /state обновлено.
- Тест `state_canary_is_deterministic_unique_and_stable`:
  ожидание вычисляется из входа (не хардкод), стабильность при
  повторном опросе, различие игр, формат. Прогон: 1 passed
  (134 отфильтровано), полный набор арены зелёный.

## Что НЕ сделано в этом срезе (честные границы)

- Фаза 1 (синтетическая дистилляция LoRA на N партий): not-executed,
  нет GPU; код и дизайн — в промпте.
- Положительный контроль детектора (виновная модель на собственных
  канарейках): not-executed, требует учебного прогона.
- Канарейки в датасет world-100-grid (главная поверхность!):
  следующий срез, требует решения о формате выгрузки.
- Проба-батарея на релизы моделей: после канареек в датасете.
