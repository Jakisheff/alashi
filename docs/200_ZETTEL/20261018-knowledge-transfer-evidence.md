# Неявное знание может оказаться биологическим рвом

Гипотеза Амира: часть знания человека и команды может не передаваться агентам ни словесным описанием, ни примерами действий. Это предполагаемый «биологический ров». В разговоре 18.10.2026 Амир связал его с коллективным бессознательным и аналогией «Jungian Paradox». Эти понятия здесь не названы одним доказанным механизмом; биологическое объяснение остаётся not_validated.

Отсутствие объяснения ещё не устанавливает непередаваемость. В alashi нужно различать знание, которое не внесли в контекст, знание, передаваемое через действия, и остаток, для которого перенос пока не проверен. Остаток нельзя автоматически считать ни саботажем, ни биологическим преимуществом.

[TEST-прототип](../../experiments/work-simulation/README.md) сохраняет эту границу в отчёте. Скриптовая таблица решений по четырём демонстрациям разрешает два из трёх новых случаев. Третий остаётся неизвестным. Референсных решений человека нет, эмоциональный интеллект не измерялся. Этот опыт проверяет устройство отчёта, а не гипотезу о биологии.

Для проверки на команде сначала записать действия эксперта на рабочих эпизодах, затем сравнить перенос через описание и через демонстрации. Оценивать новые эпизоды, сохранять референс человека и учитывать его помощь агенту. Разобрать оставшиеся ошибки: скрытый контекст, недостаток примеров, ограничение модели или бюджета. Конечная серия неудач не доказывает всеобщую невозможность передачи знания. Успешная передача конкретного знания сужает сильную гипотезу.
