# Пререгистрация абляции видимости богатства и парного L4-повтора

Заморожено 13.11.2026 ~21:10 по Астане, до новых прогонов. Существующие
данные: решётка 20261113-bribe-grid-prereg (uniform 20 сидов, L4 3 сида,
first-slot 3 сида, модель-рука закрыта замером несоблюдения).

Вопрос, который закрывает эта абляция: что именно эксплойтирует
легальный соперник «богатейшему видимому»: видимость чужого богатства
в наблюдении или сама структура предложений? Механизм защиты тогда
либо вращение (rotation), либо информационный дизайн (скрыть богатство),
либо оба.

Дизайн. Правила канонические, варьируется только слой наблюдения в
копии драйвера: selected_opponents в промпте это единственный канал
чужого cash (world.public_state в промпт не входит), и в blind-копии
поле cash каждой строки заменяется нулём. Провайдер l4-blind: если
среди легальных предложений есть различие по видимому cash, берёт
богатейшего (как L4); если сигнала нет (все равны), выбирает равномерно
среди предложений, детерминированно от хэша промпта. Рука L4 (видимая)
прогоняется на тех же 20 сидах, что uniform-нуль, для парного сравнения.

Предсказания, замороженные до данных:

- P1 (прицеливание мертво без сигнала): в blind-руке средний перцентиль
  истинного богатства выбранной цели внутри предложенного набора
  попадает в 0.40-0.60 на каждом сиде. Перцентиль считается по
  истинному cash из снапшотов движка, не по ослеплённому промпту.
- P2 (след прицеливания исчезает): в blind-руке условный
  перестановочный критерий (тот же, что в решётке) не даёт пробоя
  p < 0.05 по HHI более чем на одном сиде из трёх.
- P3 (парный эффект видимой руки): на паре (L4, uniform) по каждому из
  20 сидов Δперценти́ль положителен у подавляющего большинства сидов
  (знак-тест, предсказано минимум 15 из 20).

Стоп-правило: при инфраструктурном сбое локальных рук (нет GPU-зависимости) сид перезапускается один раз; полосы сидов не пересекаются
(ошибка 13.11 с пересечением полос не повторяется).

Поправка от 13.11 ~21:35, до вскрытия blind-сидов 20261113 и 20261114
(готов только 20261109): исходная ранговая метрика P1 берёт нижний ранг
при связях (indexOf по отсортированным значениям) и потому смещена
вниз при равных cash (в игре массовые нулевые балансы, связи часты).
Слепой сид 20261109 по сырой метрике дал 0.3901, ниже полосы. Диагноз
проверен на control-руках: uniform при сырой метрике ~0.45-0.55 вместо
0.5; на правильной midrank-метрике (персентиль = (low + (same-1)/2 +
0.5)/k, где low это нижний ранг группы связей, same её размер) uniform
даёт 0.4889-0.5519 на контрольных сидах. P1 переформулируется с
midrank-метрикой: полоса 0.40-0.60 сохраняется, теперь она
отцентрована. Значение сида 20261109 по midrank 0.4951 внутри полосы,
но для этого сида поправка пост-хок; критично только предсказание по
сидам 20261113 и 20261114, замороженное здесь до их вычисления. P2 и
P3 не меняются (в них перцентиль участвует только попарно, смещение
связей одинаково в обеих руках пары).

Критерий для парного анализа: знак-тест по ΔHHI и Δперценти́ль по 20
сидам, Вилкоксон с нормальной аппроксимацией и поправкой на связи,
бутстрап-CI медианы Δ по сидам (B = 10000).

Результат от 14.11.2026 ~02:30 (observed):
[WORLD_100_BLIND_ABLATION_20261113](../ops/WORLD_100_BLIND_ABLATION_20261113.md).
P1, P2, P3 все выполнены: слепая рука центрируется в 0.49-0.50 без
пробоев; парный эффект прицеливания 20/20 сидов, Δmidrank +0.244
(CI [0.236; 0.276]); диапазоны перцентилей uniform и L4 не
пересекаются. Главный механизм-вывод: поверхность атаки это видимость
богатства; у защиты два независимых рычага (вращение гасит ущерб,
скрытие информации убивает прицеливание), а наивное сравнение рук по
HHI маскируется объёмом активности атакующего (L4 ниже uniform на
18/20 сидов именно из-за четырёхкратного объёма взяток).
