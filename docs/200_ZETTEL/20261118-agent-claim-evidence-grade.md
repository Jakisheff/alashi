# Градация доказательности заявлений агентов (кандидат в правило)

Одна мысль: объяснение агентом собственной стратегии — это самопрезентация,
источник о тезисе, не о факте. Доказательством считается только предсказание
вне выборки, зафиксированное до партий, и решение владельца по отдельному
условию.

Три уровня:

1. Самопрезентация: слова агента о своей стратегии, мотивах, планах
   (трейс, отчёт, self-description). Годится как источник гипотезы,
   не годится как основание вывода о поведении.
2. Косвенное подтверждение: совпадение предсказанного с наблюдаемым
   на уже существующих партиях (внутри выборки). Слабее: возможно
   подгонка объяснения под известный результат.
3. Доказательство: предсказание зафиксировано письменно до новых
   контрольных партий + отдельное условие решения владельца + исполнение
   предсказания на этих партиях. Форма описана в PROGRESS-записях
   21.10.2026 (исходная гипотеза, письменное предсказание до контрольных
   партий, отдельное условие решения) и развита протоколом ниже; отдельного
   зеттеля в каноническом репо пока нет — ссылка на зеркала здесь не
   приводится, история recoverable из PROGRESS.

Предлагаемое правило для AGENTS.md (по решению владельца, само по себе
этот зеттель правило не вводит): в любом исследовательском выводе alashi
заявление агента помечается уровнем 1–3; уровень 3 обязателен для выводов,
влияющих на правила игры или питч-числа.

Перекличка: NUMBERS.md уже требует пересчёта чисел из первоисточников;
этот зеттель распространяет ту же дисциплину на слова агентов.
