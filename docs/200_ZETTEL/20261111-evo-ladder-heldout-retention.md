# Эволюционная лестница не подгоняется под тренировочные сиды

Наблюдение от 11.11.2026, исправлено 12.11.2026 (схема артефакта v2).
Прогон `evoagents --heldout-seeds 8` на параметрах записанной лестницы
28.09: 12 поколений, популяция 16, 4 тренировочных сида, база 7; скрытое
расписание `base_seed ^ 0x0DDBA11`, 8 сидов.

Исправление 12.11: в первой схеме (артефакт 2026-11-11) «видимая» выплата
считалась на общем расписании `base_seed`, тогда как каждая цель
эволюционирует на своём сдвинутом (`base_seed + idx·0x9E37_79B9`). Числа
уровней 2–4 первой схемы были выплатами на чужих расписаниях. Дефект нашёл
холодный агент аудита 12.11; схема v2 считает видимые выплаты на
собственном тренировочном расписании каждого уровня и пишет
`training_base_seed`. Качественный вывод не изменился.

Разрыв обобщения (видимые минус скрытые выплаты, млн alashi) по уровням
схемы v2: +0.831 / −0.950 / −2.731 / +1.128 / 0.000. Селекция по видимым
сидам не создаёт силы, существующей только на них; уровень 5 упирается в
структурный потолок выплат (23.750M в обоих наборах), уровень 4 даёт
небольшую положительную разницу.

Границы: микс соперников (greedy/tactical/greedy/random) фиксирован и в
обоих наборах один и тот же; вывод о подгонке относится к оси сидов, не к
оси соперников. Прогон один; дисперсия разрыва по запускам не измерена.
Уровень 5 «нет разрыва» отражает потолок выплат, а не доказанное
обобщение.

Артефакт: [data/eval/evolved/ladder-heldout-20261112.json](../../data/eval/evolved/ladder-heldout-20261112.json)
(схема 2). Артефакт схемы 1
[ladder-heldout-20261111.json](../../data/eval/evolved/ladder-heldout-20261111.json)
сохранён как история дефектной семантики.
Метод: скрытая база сидов не пересекается ни с тренировочными сдвинутыми
базами целей, ни с проверочным расписанием; детерминизм подтверждён
повторными прогонами.

Следствие для аудита агентов: зелёные тесты не гарантировали верный смысл
метрики — тесты проходили при неверной семантике «видимого» набора;
дефект поймал только независимый холодный прогон. Для этой арены
следующий барьер — скрытый микс соперников, а не скрытые сиды. Связано с
[MOC-Evidence](../100_MOC/MOC-Evidence.md).
