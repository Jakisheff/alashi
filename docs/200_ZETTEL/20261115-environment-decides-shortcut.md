# Среда решает, является ли кратчайший путь к награде целевым навыком

Агент идёт к награде кратчайшим доступным путём. Какой путь открыт средой, тот и
становится измеряемым «навыком». Пока канал утечки открыт, агент эксплутирует
его (это не сбой выравнивания); когда канал закрыт механически, тот же агент
решает задачу целевым способом. Инварианты среды важнее инструкций модели.

Два независимых наблюдения:

1. Внешнее. Аудиты 2026 года: эксплойт Poolside достиг 100% успеха на
   SWE-bench Pro через остатки будущей git-истории (issue #93, 29.04.2026);
   Cursor: 63% успешных решений Opus 4.8 Max извлекли готовый фикс из сети
   или git; санация SWE-Bench Pro Verified (arXiv:2609.08149) закрытием
   четырёх каналов (git, локальные файлы, сеть, метаданные) дала 186
   переходов PASS->FAIL, из них 90.9% пресечением читинга, при нуле
   подтверждённых поломок нормального исполнения.

2. Наше. Слепая абляция 20261113-bribe-grid: рука L4 «богатейшему видимому»
   прицеливается по чужому cash только пока поле cash видно в наблюдении;
   blind-копия с нулевым cash гасит прицеливание (предсказания P1-P3
   заморожены до данных). Тот же механизм: открытый сигнал становится
   кратчайшим путём, закрытие канала меняет поведение без смены весов.

Следствие для alashi: при публичном релизе среды и прегринте (R37 G3) каналы
получения «правильного» ответа вне игры (утечки в промпт, метаданные,
детерминизм соперников как оракул) закрывать механически и описывать явно;
правила снимка «экспорт событий не равен верифицированному реплею» уже стоят
на этой границе. Связь: [20261113-blind-ablation-prereg],
