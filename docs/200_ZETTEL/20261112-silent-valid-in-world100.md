# Тихая валидность в решениях игровых агентов: данные world-100

Наблюдение от 12.11.2026 по записанным диагностикам двух игр world-100
(9–10.11.2026, BitLLM, 100 агентов, canonical Rust rules). Сырьё:
baseline-diagnostics.json (single-winner), economic-diagnostics.json и
paired-audit.json (market-context pair).

observed, пять фактов с числами:

1. Контекст-слепота побитово. В парном прогоне единственное различие рук —
   добавленная рыночная информация в промпте фокального агента; все
   сохранённые запросы и ответы равны между руками (поле
   all_saved_requests_and_responses_equal_across_arms=true). Прогон валиден
   и воспроизводим; агент доказуемо не использовал информацию. Дешёвый
   детектор: побитовое сравнение рук чувствительности.
2. Тихая субоптимальность в масштабе: 526 actor-round пар menu_gap
   (покупка доступна по цене исполнения, средств хватает, покупка не
   совершена), 42 не созданных бесплатных товара, 21 ранний проход. Всё
   валидно по меню, невидимо ни одному гейту.
3. Единственный громкий отказ: 1 отклонённый вне-меню выбор на 1806
   решений (0.06%). Конвейер блокирует незаконное и не видит
   субоптимального: громкое редкое, тихое массовое.
4. Микро-община взяток: 14 приняты, 70 млн отправлено, только 4 дали
   немедленное президентство; победителю пришла одна взятка (5 млн,
   раунд 4). Агенты платят за неопределённый результат — общий ресурс
   (влияние) расходуется шумно.
5. Выплат больше нуля: 4 из 100 (winner-takes-all по конструкции); в
   canonical top-4 исторически 80.56% крупнейшему — второй прогон после
   фикса меню взяток дал 7.14%, replay подтвердил. Двухпрогоновая
   история «нашёл дисбаланс → починил → подтвердил» — модель
   воспроизводимогоBalancer-фикса для игровых метрик.

not_validated: одна модель, две игры; частоты не есть вероятности;
menu_gap измеряет упущенные покупки относительно записанного порядка
исполнения, а не контрфактическую optimum-стратегию.

Следствие для аудита: слой agent-decision добавляется к таксономии
silent-but-valid (кейс context-blind-bit-equal в датасете
Jakisheff/silent-but-valid). Кандидат на проверку: повторная пара рук с
другой информацией — предсказание бит-равенства записано в
PREDICTIONS (W2). Связано с [MOC-Evidence](../100_MOC/MOC-Evidence.md) и
[20261112-pasture-flat-gap](20261112-pasture-flat-gap.md).
