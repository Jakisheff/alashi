# Лицензия бьёт ранг

В партиях №10-19 (8 из 8) держатель лицензии брал топ-выплату, независимо от места в таблице. Механика: рента с лицензии капает поверх ранговой доли. Пример №18: Zhambyl собрал 59.08M (81% банка) при ранге 1, внешний Айнид с рангом 0 получил 10.4M.

Следствие для баланса: рынок сам вышел на равновесную цену бидов 21-29M, жалоба «лицензия слишком сильная» снята рынком.

Следствие для продукта: правило двигает деньги сильнее победы, это ядро питча и репортов.
