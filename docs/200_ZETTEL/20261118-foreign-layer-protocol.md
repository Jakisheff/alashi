## 2. Протокол на будущие случаи

Чужой слой в рабочем дереве перед коммитом проходит пять шагов:

1. Провенанс: поиск по заголовку/ключевым словам в PROGRESS, HANDOFF,
   STATUS, каноне владельца; mtimes против истории коммитов. Невосстановим —
   пометить «сирота» в коммит-сообщении и PROGRESS.
2. Верификация: суммы и счётчики против манифестов; выборочная сверка
   5 ссылок; секрет-скан.
3. Дрейф: диф состояния автора..HEAD по покрытым файлам; доля устаревших.
4. Классификация: docs / генерированные (проверить воспроизводимость
   командами из заголовка; невоспроизводимые — архивная пометка) /
   кандидаты на исключение.
5. Коммит отдельным слоем с ссылкой на этот протокол; чужие слои
   не смешивать с текущей задачей.

Ветвь «провенанс невосстановим»: слой принимается только после шагов 2–4
и с явной пометкой; при расхождении чисел или мёртвых ссылках > 30%
выносится решение владельца о включении.
