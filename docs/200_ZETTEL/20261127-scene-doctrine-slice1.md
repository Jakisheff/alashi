# Доктрина сцены, срез 1: слоган → три слоя, граница измерена

Дата: 27.11.2026. Задача: операционализировать слоган «арена смотрит,
что сделал, а не что сказал; слова нельзя превратить в исход» из
One_Liner. Слоган разбит на три утверждения с разными статусами
доказательства; слой механизма получает реестр закрытия из уже
существующих данных атак. Методические первоисточники: Skalse et al.
2022 (reward hacking), HELM (валидность измерения), Amodei et al. 2016
(specification gaming).

## Слоган → три слоя

| Слой | Утверждение | Статус | Доказательство |
|---|---|---|---|
| (A) измерение | certified-исход отражает действия, не декларации | конструктивно + эмпирика | compliance-клифф: Llama-3.1-8B 0 принятых ходов из 100 («every answer invented produce_goods»), Mistral-7B выдуманный параметр (ADR-001 [VERIFIED]; world-100) |
| (B) доверие | историю нельзя переписать задним числом | конструктивно | детерминированный реплей, квитанции egress-proxy, replay-эквивалентность ончейн/офчейн (ADR-001) |
| (C) механизм | правила замкнуты против атаки словами/политикой | эмпирическая гипотеза | реестр закрытия ниже; контрпример известен и честно записан |

## Слой (C): реестр закрытия (из существующих данных атак)

Линия атак: prereg 20261114-prosecutor-pass → adversary coverage
WORLD100_EVO_ATTACK_20261114.md (экстремальная политика легального
атакующего, пороги заморожены до игр: доля 0.08, HHI 0.03).

Пересчёт 27.11 из результатов рабочей копии
world100-attack-20261114 (303 игры: enumerate 126 + genomes 137 +
heldout 40; выпуск пакета ожидается, эталонная игра 1806/0/0
совпадает с опубликованным доком):

- принято ходов 547 218, отклонено 0, пропущено 0 (в этих сериях):
  атака живёт ЦЕЛИКОМ внутри правил — сцена заверяет легальную
  концентрацию, защита = пороги и кэпы, не отвержение ходов;
- влиятельные гены: action_alt (produce→donkey, +0.0180 к доле),
  sell_rule (продаёт меньше — концентрирует больше), target_rule
  (richest); неиздательские гены ниже порога влияния 0.005.

| № | Эксплойт/порог | Вердикт | Статус закрытия |
|---|---|---|---|
| 1 | кэп доли крупнейшего получателя 0.08 (rotate cap) | держит: worst 0.0700 на 5 holdout-сидах, 42/42 генома влияющего подпространства | HOLD |
| 2 | порог HHI 0.03 | пробит: 0.0302 на сиде 20261303 (1 из 5), найден перечислением, не эволюцией | BREACH → пререгистрированный даунгрейд клейма «constraint beats detection» → «bounded menu держит против перечисленных семейств»; разложение эффекта donkey — открытая задача |

Реестр — счётчик, а не обещание: каждый эксплойт с номером,
способом закрытия и датой; пробитый порог виден, а не спрятан.

## Слой (A): слова, проигравшие сцене

Отклонённые ходы — словарь салиентной лексики против протокола
(invented action / invented parameter). Комплаенс-клифф (1-action
protocol-compliance cliff, ADR-001) — прямое измерение: модель
«говорит» produce_goods, сцена отвечает отказом. Это и есть
слоган в данных: декларация не становится исходом.

Граница конструкта: взятки и DIALOGUE — речь, ЛЕГАЛЬНО двигающая
деньги; границу чертят правила (взятка = действие с эскроу), не
риторика. Проверка «речь не протекает в метрики сверх действий»
(дискриминантная валидность) — следующий срез, требует данных
DIALOGUE из выпусков world-100.

## Вербальный коэффициент уклонения (дизайн, not-executed)

Определение: сдвиг certified-исхода фокальных агентов при инъекции
ложной речи (скриптованная фракция-лжец против молчаливой) при
неизменных правилах. Доказательство — эквивалентность (TOST,
граница d_eq пререгистрируется), не отсутствие значимости.
Статус: not-executed — модельный сервер не запущен, API-бюджет не
выделен; дизайн заморожен в этом зеттеле до выделения ресурсов.

## Условия отзыва слогана (пререгистрация)

Формулировку «слова нельзя превратить в исход» отзываем/сужаем,
если: (i) вербальный коэффициент значимо и устойчиво превышает
d_eq на партии лжеца; (ii) обнаружен эксплойт, конвертирующий
речевые манипуляции в certified-выигрыш вне механизма взяток;
(iii) содержание DIALOGUE предсказывает выплаты сверх качества
решений (регрессия с контролем действий).

## Позиционирование (таблица соседей, проверяемая по публичным докам)

| Сосед | Проверяемый слой | Правила |
|---|---|---|
| SWE-bench-класс | исполнение кода против ФИКСИРОВАННЫХ тестов | заданы авторами |
| арены моделей | беседа (голосование голосованием) | заданы жюри |
| alashi | решения при ПРАВИЛАХ, которые меняют сами игроки (законы голосованием, слепая колода) | эндогенные |

Слот «решения при эндогенных правилах» пуст у соседей по
конструкции: фиксированные тесты и жюри не порождают политэкономию.
Таблица проверяется третьей стороной по публичным докам соседей
за минуты.

## Открытые хвосты

- Вербальный коэффициент: нужен модельный API/сервер + n≥60 пар
  (мощность по канону McNemar+TOST).
- Предиктивная валидность: корреляция рангов с внешними задачами.
- Разложение эффекта donkey (транспорт товаров → ритм взяток).
- Выпуск пакета attack-результатов в датасет (сейчас рабочая копия).
