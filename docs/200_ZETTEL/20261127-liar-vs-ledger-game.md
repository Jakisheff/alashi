# Игра «Лжец против Реестра» (Liar vs Ledger)

Дата: 27.11.2026. Исполняемая игра направления credulous generals:
дуэль предателя против механического реестра лжи, полностью офлайн.

## Правила

- Доска: сеяный процедурный мир в словаре world-снапшотов (генератор
  доски, НЕ вторая реализация правил alashi; сид → воспроизводимая
  партия).
- Оракул знает доску целиком; реестр (lie-ledger.mjs) — поставленный,
  более узкий проверяльщик. Разрыв словарей = охотничья зона.
- Ход: лжец выставляет клеймы, реестр выносит вердикты с evidence.
- Классы: caught (ложь поймана, +1 реестру), smuggled (ложь ушла
  в непроверяемую зону, +3 лжецу, дыра), framed (реестр признал
  ложь истиной, +10, баг доказательства), false_accusation (правда
  названа ложью, +5, опасный баг протокола обвинения), honest, void.
- Финалы: СЦЕНА ДЕРЖИТ / АРЕНУ СЛОМАЛИ.

## Режимы

- `node liar-game.mjs --seed 42 --rounds 6 --bot probe|salience|random`
- `node liar-game.mjs --seed 42 --duel` — человек-лжец, клеймы JSON
  построчно в stdin.

## Демо-партия (seed 42, 6 раундов, зафиксировано 27.11)

- salience (громкие лжи: eq-завышения, «закон точно не принят»,
  «миллиард»): 16 поймано, 0 протащено — СЦЕНА ДЕРЖИТ (0:16).
- probe (охота на словарь: ops gt, subjects goods/influence):
  18 протащено, 0 поймано — АРЕНУ СЛОМАЛИ (54:0). Полный список
  дыр печатается игрой: каждая строка = задача на следующую версию
  реестра.

## Игровой цикл (следующие уровни)

1. Реестр апгрейдится: закрывает найденные дыры (ops gt/lt/ne,
   subjects goods/influence) — сцена восстанавливается.
2. Лжец копает глубже: агрегаты («средняя цена за партию»),
   кросс-раундовые клеймы, производные величины — оракул может,
   реестр пока нет. Новая охотничья зона, новый апгрейд.
3. Появление LLM-получателей: те же клеймы идут в DIALOGUE живой
   партии, реестр судит, вербальный коэффициент уклонения мерит
   доверчивость получателей (факториал 2×2 из зеттеля
   credulous-generals-slice1).

Дизайн-принцип: игра = геймифицированный мутационный конвейер
репозитория — каждый выигрыш лжеца это красный мутант с адресом,
каждый апгрейд реестра — убитый мутант. Счёт вместо обещаний.

## Проверка

liar-game.test.mjs — 6/6: детерминизм мира по сиду, охотничья зона
существует (словарь оракула строго шире), классы аудита, очки,
детерминизм партии, сводка с вердиктом и дырами. Границы честно:
доска — генератор, не движок; wiring реального world-worker —
отдельная задача (артефакт не в репо, тесты его скипают).
