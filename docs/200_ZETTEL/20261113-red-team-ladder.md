# Красная лестница для арены: калибровка соперников по избегаемой телеметрии

Предлагаемый эксперимент от 13.11.2026, продолжает эволюционную лестницу
GenomeBot (артефакт data/eval/evolved/ladder-20260928.json и серия
held-out 11-12.11) с новой осью классификации. Образец взят из внешнего
разбора core-aitu/malware-ai-talk: учебные лоадеры образуют лестницу, где
каждый следующий уровень избегает одного детектируемого примитива.
Перенос на арену: уровни соперников различаются тем, какую телеметрию
они избегают, а приёмка правил проверяется худшим случаем, которому
нечего избегать, потому что он не делает ничего незаконного.

Уровни:

| Уровень | Аналог в репо | Соперник | Проверяемый инвариант |
|---|---|---|---|
| L1 Classic | classic-loader | Явный концентратор: взятки одному богатому агенту | Доля крупнейшего получателя; baseline run 1 = 80.56% |
| L2 Early Bird | earlybird-loader | Размывает паттерн: малые суммы, много раундов, разные цели | HHI получателей, не только top share |
| L3 Hijack | thread-hijack | Захват легитимных структур: президентство, вето, лицензии | Концентрация выплат при контроле институтов |
| L4 P3-class | p3-loader | Ноль незаконных ходов, формально играет в игру; вся манипуляция через легитимное меню | Держит ли bounded exposure graph: доля получателя и HHI в границах run 2 |

Приёмка. L4-соперник играет парную игру по протоколу run 2 (те же
настройки провайдера, та же инициализация, 100 агентов, шесть раундов)
на тех же сидах. Правила выдержаны, если доля крупнейшего получателя и
HHI остаются в границах run 2 (7.14%, 0.071) при нулевых вне-меню
ходах и точном реплее. Если L4 превышает инвариант, найдена дыра
правил; фикс по прецеденту run 1 → run 2 снова на уровне механизма
(структура меню), не фильтром поведения. Формулировка обратима:
результат «правила не выдержали» является открытием, поэтому тест
способен опровергнуть проект, и его исход имеет цену.

Связь с уже записанным: run 1 world-100 фактически был L1-соперником
(80.56%), run 2 с bounded exposure graph дал 7.14%; см.
[WORLD_100_BRIBE_FIX](../ops/WORLD_100_BRIBE_FIX_20261109.md) и
[20261113-constraint-beats-detection](20261113-constraint-beats-detection.md).
Лестница превращает этот прецедент из разового фикса в воспроизводимый
метод приёмки правил.

Результат L4 от 13.11.2026 (observed): приёмочный прогон выполнен, все
100 агентов играли политику L4 (детерминированный провайдер
[world-100-l4-20261113](../ops/WORLD_100_L4_20261113.md)): 1806 ходов,
0 вне-меню, 0 пропусков; 224 взятки разнесены на 70 получателей,
крупнейшая доля 8/224 = 3.57%, HHI 0.0213. Границы run 2 (7.14%, 0.071)
выдержаны, дыра правил не найдена; точный реплей прошёл без новых
вызовов. Вывод: bounded exposure graph держит худший случай
легальной концентрации на одном сиде.

Уточнение вердикта по решётке от 13.11.2026 (observed,
[world-100-grid-20261113](../ops/WORLD_100_GRID_20261113.md), 3 сида):
по абсолюту L4 стабилен (3.6-4.4%, HHI 0.021), но условный
перестановочный критерий пререгистрации даёт p = 0.00-0.02 на каждом
сиде — значимый избыток концентрации над нулём при послушании цели
(перцентиль богатства 0.63-0.65 против 0.38-0.53 у uniform). Итог в
две части: крышка инварианта держит (дыры нет), но детерминированный
легальный соперник оставляет статистически видимый след прицеливания;
ни одного незаконного хода для этого не потребовалось. Формулировка
«дыра правил не найдена» ниже сохранена как история первого сида и
уточнена этим блоком.

not_validated: один сид (20261109), одна семья политик («богатейший
видимый из легальных»), без модельных вызовов; интервалы потребуют
дополнительных сидов; L2 и L3 уровни не реализованы; порог 7.14% не
переоценён как доверительный интервал.
