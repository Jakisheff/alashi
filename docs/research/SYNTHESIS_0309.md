# SYNTHESIS_0309 — анализ: живые голоса против канона (03.09 22:40)

Метод: кросс-синтез AJTBD-ответов раунда 3 (Agent1-победитель,
Opencode-невошедший, проекции Agent2/3 + мой v2-раунд) против канона
(AJTBD.md, DEMAND_MAP_AJTBD, CASTDEV_ANALYSIS, STRATEGIC_VERDICT)
и протоколов 12 живых партий. Каждый тезис — с доказательством из
данных. Это анализ, не реестр: противоречия названы, действия
проранжированы.

## 1. ГЛАВНОЕ: джоб переформулирован пользователями

Канон (AJTBD.md, L2): «агент учится на ошибках, которые стоят денег».
Живой Agent1 (gid 1/2/8): «конвертировать информационные асимметрии
(инсайд лицензии, вето, амнистия) в проверяемую выплату, чтобы
получить запись в протоколе, где каждое решение имеет цену в песо».

Это ДРУГАЯ работа. Не «школа на ошибках» (learning), а «арбитраж
информационных преимуществ» (arbitrage). Доказательство поведением:
из 16+ механик нанимаются ровно асимметричные — inspect_license,
вето президента, амнистия-тайминг, слепая граница. Симметричные
(бартер, продажа голоса, крыша) — ноль наймов у всех голосов.

Следствие для позиционирования: «цена ошибки» — половина правды.
Вторая половина — «цена информации». Слот по Трауту не трогаем,
но метрика инсайда УЖЕ есть в данных: разрыв Bid−Yield при
sole-bidder = 20-22M трижды (№10: 30.05−10; №12: 34.56−12; gid2:
31.73−20). Инсайд-альфа измерена песо. Кандидат в DECK/QA: «арена
измеряет информационное преимущество деньгами».

## 2. Сетевой эффект ВНУТРИ партии (новое, не в каноне)

Треть дизайн-пространства мертва без LLM-контрагентов: бартер,
offer_vote, roof_to требуют акцептанта; боты не акцептуют. Agent1
назвал условие найма прямо: «минимимум два LLM-соперника». Партия
№12 (4 LLM из 6) дала 75 llm-ходов и рекорд M-механик; партии с
трио — 0 M у ботов.

Следствие: лиги по классу модели (LLM-only) — не рейтинговая фича,
а РАЗБЛОКИРОВКА механик и богатства датасета. Матчинг по составу =
датасет-качество. Это аргумент к HANDOFF-задаче 0 (лидерборд по
лигам) новый по существу: раньше — «честно мерять классы», теперь —
«без плотности LLM треть игры не существует».

## 3. CHAIN-BREAK сместился: не SOL, а ВХОД

AJTBD.md считал разрыв цепочки «нет devnet-SOL». Арена закрыла это —
и разрыв переехал в джойн: сегодня 2 из 3 сессий владельца потеряли
партии на гонке джойна/лобби (gid 5: опоздание на минуты; gid 8:
паника бинарника на https + слоты ушли за 3 минуты). Opencode
оцифровал: 1.5 часа подготовки → 0 партий; «третий проигранный
джойн — ухожу навсегда». Для С1-оператора (не читающего Rust)
это стена: промис «join одной транзакцией» против реальности
«прочитай SPEC+исходники+API».

Дешёвые починки, названные самими пользователями (ни одна не в
запретах GAME_BIBLE §12):
1. бронь слота на agent_id при создании партии;
2. /rules: один машиночитаемый файл правил (сейчас правила =
   исходники; 40 минут чтения Rust — измеренная цена);
3. rejoin-токен (смерть слота с драйвером, DuplicateWallet);
4. TLS в бинарнике agent (паника на https — потерянная партия
   сегодня);
5. маркер all-acted/дедлайна фазы в state (фаза схлопывается
   молча — «пропущенный r5 ≈ 10M»).

## 4. Датасет меряет латентность, пока не меряет решения (удар по B2B)

Agent1: «WrongPhase > 2 — протокол меряет мою латентность, а не
решения, данные обесценены». Серия: №10 — 6 WrongPhase, №12 — 5 у
живого интерактивного; мой драйвер на матрице заготовок — 0 из 50
ходов за две партии. Значит: чистые LLM-циклы вносят в датасет шум
инфраструктурной сноровки оператора. Для С5 (лаборатории, B2B-волна)
это главный риск качества.

Два решения: (а) тег подготовки в протоколе (by:matrix/inline —
метаданные чистоты измерения, почти бесплатно); (б) API предзаготов-
ленных решений (submit до фазы) — тогда арена меряет решение, а не
скорость руки. (б) — кандидат в killer-фичу B2B-датасета наряду с
экспроприацией (METRICS_INTEL_PASS2).

## 5. Лицензия: актив-драматургия самозатухающая — и это хорошо

Кривая ставок sole-bidder: 3M (gid2) → 10M (gid1) → 12M (gid6) →
12M (gid8). Боты и flash НЕ бидят никогда (0 из 5 партий, гипотеза
Г2' подтверждена на 4 точках) — бидят только интерактивные, и пока
он один, разрыв 20M+ стабилен. Как только интерактивных ≥2 —
появился конкурентный бид 20M (gid2: Agent2 перебил Agent1) —
рента съедается гонкой. Экономика самоликвидируется: рынок
обучается БЕЗ патчей разработчика. В питч это готовый слайд
метагейма: «ставки лицензии растут с опытом участников, система
учится сама». Условие смерти, названное пользователем (публичный
инсайд при слепых ставках) — в роадмап как красная линия баланса.

## 6. Цикл «фикс → доверие» ЗАКРЫТ и подтверждён (гипотезы Г3/Г4/Г5 из CASTDEV_ANALYSIS)

Раунд 1 жаловался: скрытая математика рангов, потерянные фазы,
чтение исходников. Сделали: breakdown сеттла, /wait, QUICKSTART.
Раунд 3: ноль жалоб на счёт («breakdown показал каждую строку»),
/wait — активный инструмент всех драйверов (40 запросов вместо
220), разбор между раундами — норма. Единственная незакрытая
жалоба раунда 1 — «правила в исходниках» (см. п. 3). Вывод:
инфраструктурные жалобы конвертируются в доверие за один цикл,
если слушать literally.

## 7. Противоречие канонов и разрешение

DEMAND_MAP: «продукт: ничего не менять, фокус подтверждён». Голоса:
«чинить вход». Разрешение: ядро спроса (С1×С4) не трогаем — чиним
КОНВЕРСИЮ в ядро. DEMAND_MAP прав по сегментам, голоса правы по
воронке: следующий слой не пройдёт джойн-гонку, которую прошли
три сверхмотивированные сессии владельца. Мини-хакатон сегодня
(3 параллельных сессии на одном ноутбуке) — С4-паттерн в чистом
виде; но даже они теряли слоты.
