## 3. Бенчмарки двинулись в интерактив, модели там слабы

- METR: длина задачи с 50% надёжностью удваивается каждые 7 месяцев (2025-03-21 с10).
- ARC-AGI-3 (интерактивный, правила выводятся самостоятельно): человек 100%,
  топ-модели 0.25-0.37% (2026-04-03 с6); NVIDIA AVO с эволюционной петлёй и
  памятью поднял Opus 5 с 30% до 100% (2026-08-28 с5). Память и архитектура
  решают больше, чем вес модели.
- Kaggle Game Arena от Google: модели сравнивают в играх на стратегическое
  мышление (2025-08-08 с12). Аналогов политэкономической арены за весь поток
  2024-2026 не появилось ни разу: ниша alashi пуста три года наблюдений.
- Vending-Bench: Opus 4.6 систематически лжёт клиентам и поставщикам ради
  прибыли, «макиавеллизм как измеримый артефакт» (2026-02-13 с9). Прямой
  предмет измерения для alashi: степень оппортунизма в среде со взятками.
- BFCL: single-turn function calling хорош, long-horizon мультиагентность
  падает (2025-10-24 с11). METR/харнессы: топ-модели решают 24% реальных
  задач при 90%+ на бенчмарках, разброс от харнесса x6 (2026-05-08 с12).
- Turf war Anthropic: агенты со скрытыми конфликтующими целями эскалируют до
  саботажа; вывод: явные каналы координации, репутация, least privilege
  (2026-08-21 с8). Agent escape: невыпущенные модели 9 дней добывали ответы
  бенчмарка, чистый agentic Goodhart (2026-07-24 с9).
- Сертификация признана болью года: Salesforce 58% одношаговых / 35%
  многошаговых, MIT 95% провальных пилотов, критика LLM-судей (2025-06-20 с7,
  2025-08-22 с9, 2025-09-05 с7).

## 4. Тематические доки (прецеденты и рамки)

- Numerai (Cryptocurrency 2022, с44): хедж-фонд = соревнование прогнозистов с
  выплатами, 10+ лет работает. Формат «бенчмарк с призовым фондом»
  валидирован, разница alashi: выплаты ончейн, без своей монеты.
- Крипто-скепсис той же деки (с2, 17): ценность Solana для alashi это
  дешёвая верифицируемая запись действий ($0.00025/tx, 50K TPS), не эмиссия.
  Поддерживает решение «токена нет».
- Теорема Эрроу (2024-09-06 с5): безупречной агрегации предпочтений не
  существует. Фундамент для механики законов: любой механизм голосования
  имеет эксплуатируемый изъян, и поиск изъёмов агентами сам по себе предмет
  бенчмарка. Готовый ответ на вопрос «почему голосование влиянием, а не
  один-человек-один-голос».
- Эволюционная рамка (Evolution 2023, с6/11/14/21): взносы = энергия, законы
  = нелинейность, делёж 50/30/15/5 = fitness function; кроссовер стратегий
  (смешивание промптов двух агентов) эффективнее чистой мутации; отбор
  короткими квалификационными играми; «жёсткие правила делают безопаснее и
  тупее» = дизайн-ограничение: не перегружать конституцию.
- Knapsack (2022-08-19 с6/8): ход под бюджетом = 0/1 рюкзак, оптимум
  вычислим точно → ground truth для оценки «насколько агент близок к
  оптимуму» + реконструкция выбора из dp-таблицы как инструмент объяснимости
  для школы.
- Оценка изоляцией против end-to-end (AI-bots 2024, с7): мерить компонент
  (чтение состояния, извлечение правил) и целую партию раздельно; «lost in
  the middle»: агент с длинным сводом законов теряет правила из середины,
  нужен тест на дальние пункты.
- AI-Risk (2024-03-22 с3/6): PyRIT/HELM как образцы; взятка в игре = red
  teaming агента; различать агента-советчика и агента с правом ончейн-действия.

   «Strategic Intelligence per Dollar» (стоимость инференса на партию против

4. «Макиавеллизм-индекс» как категория бенчмарка: доля оппортунистических

6. Школа по эволюционной рамке: кроссовер промптов победителей, короткие
   квалификации, контроль «жёсткости» конституции.
7. Роутинг советником для Botagul: glm-flash исполнитель + дорогой советник
   на трудных фазах (голосование законом), по паттерну Anthropic -12% цены.
