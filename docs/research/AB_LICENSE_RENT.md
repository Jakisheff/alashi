# A/B: рента лицензии в ранге против канона (поверх ранга)

Дата: 02.09.17:25. Причина: рефлексия Agent2 (REFLECT_SELF) — победитель
аукциона жертвует долей банка (ставка уходит из кэша до сеттла, рента
приходит поверх доли): правило стоило ~34.2M при ренте 31.7M.

Метод: simrun 400+400 партий, эпоха 90-х, микс greedy,random,tactical,
одинаковые seed (4242), меняется только режим сеттла
(`--rent-in-rank`): рента либо в ранге держателя (вариант «а»), либо
сверх доли как сейчас (канон). Бид-эвристика фиксирована: tactical 8M,
greedy 4M в r4. Реализация: compute_settlement_epoch(external_rent,
rent_in_rank) — прод-пути не менялись (оба флага false в ончейне,
арена external_rent=true).

## Результаты

| Метрика | КАНОН (рента поверх) | рента в ранге |
|---|---|---|
| EV выплаты лицензиара | 54.3M | 19.9M |
| средний ранг держателя | 0.96 | 0.09 |
| лицензиар в топ-2 по рангу | 333/400 (83%) | 399/400 (99.8%) |
| победы tactical / greedy | 88 / 285 | 358 / 36 |
| средняя рента | 41.3M | 0 (в ранге) |
| средняя ставка | 7.9M | 7.9M |

## Вывод: оставить канон (вариант «в»)

1. «Рента в ранге» = «богатый богаче»: держатель почти всегда (99.8%)
   становится ранг-1, лицензия превращается в доминирующую стратегию,
   tactical забирает 90% партий. Умирает ключевой паттерн датасета
   «4 партии — 4 разных победы» (лицензия дважды делала богатейшим
   не-победителя) — это наш главный маркетинговый актив.
2. Канон сохраняет нетривиальное решение: ставка честно жертвует
   рангом (топ-2 только 83%, ранг 0.96), но EV лицензиара выше (54.3M)
   — «власть за деньги» работает как задумано, асимметрия информации
   живая.
3. Морейнис №3 (лучше в разы по критерию выбора): вариант «а» не
   делает игру лучше ни для одного сегмента — только сжимает
   пространство стратегий.

Данные: /tmp/opencode/ab_rent_{off,on}.jsonl (по запросу перенесём в
data/sim/). Вопрос из IDEAS_PARKED закрыт: правило остаётся каноном.
