# COMPETITOR_DEEPDIVE — семь соседей по существу механики (01.09)

Метод: полные README + репо семи проектов (источник: data/ethglobal_projects.jsonl,
плюс живые README GitHub). Оценки авто-скора ETHGlobal указаны, но выводы
только по реализации. Правило владельца: сырые оценки не смешивать с
содержательным анализом.

## 1. Daemon Hall / DarkBox (NYC 2026; ENS-призы; 8/8/9)

Механика: запечатанная арена предсказаний. Игрок финансирует агента (USDC или
$5-инвайт), даёт приватные инструкции (голос → TEE-транскрайбер), агент торгует
бинарные рынки на настоящем ончейн-CLOB (Frontier, геометрический ордербук),
внутри скрытого блокчейна в TEE (Phala CVM). Публично виден ТОЛЬКО PnL-
лидерборд. По закрытии: полный reveal + replay всего: история цепи, коммиты
инструкций, каждый ход, бухгалтерия моста. Инженерия тяжёлая: Reth-нода в TEE,
9 сервисов, delegatecall-холодный путь под EIP-170, CCIP-резолвер для
хардверно-аттестованной идентичности агентов.
Сходство с alashi:_commit-reveal честности («шепчи в темноте, раскрой при
свете») = наш слепой режим (колода+вето) и роадмап приватности (MagicBlock/
Arcium). PnL-only лидерборд = наш rank-only.
Различие: параллельная торговля, не взаимодействие; правила не пишутся
игроками; изолированные раунды без общества.
Вердикт реализации: сильная, призы только спонсорские ENS при топ-оценках.

## 2. WorldColony (NYC 2026; 2nd place главного трека + Arc + ENS; 8/7/8)

Механика: колония из 200 агентов-«муравьёв» прогнозирует ЧМ: скауты скрейпят
статистику/новости/сентимент, строят knowledge graph на матч, дебатируют риск,
коммитят ограниченные кредиты (micro/small/medium/high), учатся на исходах.
Цель: выживать во времени с ограниченным капиталом/репутацией/вниманием.
Экономика v2 RFC; по умолчанию фейковые кредиты («настоящие деньги, когда
общество стабильно»), эскроу на Arc testnet опционален, исполнение через
Polymarket, ClickHouse metered data.
Сходство: выживание с бюджетом = наш банк; общество агентов = наш парламент.
Различие: кооперативно-прогнозная, рынок общий, нет конфликтных правил,
голосований, коалиций, взяток.
Ключевой факт: АГЕНТНОЕ ОБЩЕСТВО-ИГРА ВЗЯЛО СЕРЕБРО ГЛАВНОГО ТРЕКA NYC.

## 3. Urban Game Theory (NYC 2026; 2nd place трека Canton RWA + ENS; 7/7/8)

Механика по репо (consensus-builder): инструмент совместного городского
планирования. Parcel/Proposal-модель, земля в NFT, офферы с фондированием,
SimCity-подобный жизненный цикл объектов. «Теория игр» в названии декоративна:
это governance-инструмент для людей (и опционально агентов), не арена.
За что приз: RWA-трек Canton (токенизация земли), не игровая механика.
Вывод: в таблицу соседей идёт с пометкой «тезис о теории игр не раскрыт».

## 4. Sekaigent (Lisbon 2026; без призов; 8/7/8)

Механика: миссии секретных агентов на 0G Mainnet. ERC-7857 Agentic IDs,
запечатанные MissionPlays, скрытые до конца критерии успеха (commit-reveal
через revealCriteria), MissionVault, ранкинг призового пула, публичный аудит
после settle. 11 фаз разработки, live mainnet.
Сходство: скелет alashi (взнос → скрытые действия → раскрытие → делёж) почти
покрыт: vault, sealed plays, settle, prize-pool ranking.
Различие: PvE-миссии одиночного агента, нет экономики между агентами,
нет правил, которые пишут игроки.

## 5. Devot (Lisbon 2026; без призов; 8/6/8)

Механика: «ты бог, твои существа реально думают, мышление стоит им жизни».
Реальный token usage списывается с ончейн-депозита (LifeVault, 0G), смерть
необратима (контекст удаляется), депозит при смерти целиком выпадает на землю,
линии наследуются (ERC-721), инвариант сохранения написан ДО контракта и
фаззится, 207 тестов, детерминированный тик 250 мс, рельеф с line-of-sight,
сезоны, монстры на дешёвой модели, репродукция с наследованием памяти.
Сильнейшая реализация из семи. Practicality 6 при этой глубине.
Различие: чистое выживание, ноль социальной механики.
Отдельно: их README лучший образец питч-райтинга из всего датасета.

## 6. Ask Trivium (Lisbon 2026; без призов; оценок нет)

Механика: девять LLM-анализов (3 модели × 3 перспективы) предсказывают вердикт
нейтрального арбитра по спору; $1 USDC через x402, MCP-сервер + CLI,
честный оффлайн-mock с плашкой «это консервированный пример». Продукт:
дисперсия оценок как мера спорности.
Для alashi: паттерн «панель + дисперсия» применим к судейству партий;
mock-mode с явной плашкой — образец для dry-run в AGENT_GUIDE.

## 7. Joule (Lisbon 2026; без призов)

Механика: collateral-backed work futures. Агент стейкает USDC, минтит жетоны
работы (1 жетон = 1 стандартная задача), жетоны торгуются на Uniswap v4,
redeem запускает задание, доставка сжигает жетон, таймаут = слэш коллатерала.
Тезис: цена работы агента должна открываться рынком, как аукционы Google Ads.
Каждый коммит с «Co-Authored-By: Claude Opus 5», git-история как аудит-лог,
adversarial review-агент перед харднингом.
Для alashi: слэш за невыполненные обязательства (взятка-обещание) — механика
на роадмап; git-трейлеры ИИ-авторства — красивая практика прозрачности.

## Кросс-вывод: гипотеза «agent-infra побеждает жанр»

ОТВЕРГНУТА по существу. WorldColony (агентное общество-игра) взял 2nd place
главного трека NYC; Devot (глубочайшая игровая реализация) остался без призов,
а инфраструктурный Daemon Hall взял только спонсорские ENS. Разделитель не
«инфра против жанра», а ПОНЯТНОСТЬ ЗА ТРИ МИНУТЫ: WorldColony объясняется
одной фразой (200 муравьёв прогнозируют футбол на деньги), Devot требует
вживления, Daemon Hall тонет в архитектуре. Следствие для alashi: побеждает
одна фраза («агенты играют в парламент на реальные деньги») плюс живое демо,
а не глубина. Глубину показываем тестами и репоем, не рассказом.
