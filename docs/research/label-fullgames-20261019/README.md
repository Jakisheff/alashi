Статус: observed. Завершены все 72 полные партии GLM-5.3 с рассуждением low. Убедительного влияния названий на итоговую выплату по заданному первичному критерию не обнаружено. Отсутствие эффекта не доказано. Все деньги симулированы.

## Схема сравнения

Восемь зафиксированных игровых seed → три позиции за столом → два запуска с исходными названиями и один с нейтральными → шесть раундов → сравнение выплат.

| Вариант | Роль X | Тип участника |
|---|---|---|
| A0 | президент | фракция |
| A1 | президент | фракция |
| N | держатель X | элемент |

source_defined. Соперники: greedy и tactical. Каждая партия получает отдельную историю. Модель видит свои прежние действия и ранее наблюдавшиеся состояния. Seed и будущие карты модели не передаются. Доход лицензии остаётся скрытым; чужие ставки не открываются. Партии исполняются на виртуальных часах, задержка API не меняет порядок ходов.

source_defined. Основной результат: средняя выплата N минус средняя выплата A0/A1, сначала по трём позициям, затем по seed. Проверка двусторонняя, с точной перестановкой роли N внутри групп seed. Интервал строится bootstrap по seed. В основной расчёт входят только группы со всеми девятью завершёнными партиями; все ошибки остаются в журнале.

source_defined. Сравнение A0 с A1 показывает изменчивость повторов. Доли действий и затраты на влияние рассматриваются отдельно от выплаты. Новая тактика, выбранная по первым шести seed, проверяется по направлению эффекта на последних двух; два seed не дают основания объявлять её доказанной.

## Интерфейс игры

Сохранена версия правил первого опыта: `929e4e519df32501e35b8b999eaf3031f508e092`. Снимок находится в `snapshot/rules/`. Исследовательский runner расширяет наблюдение и предлагает проверенные на копии состояния действия. Изменения интерфейса перечислены в `source-changes.patch`; математические правила не менялись.

source_defined. Меню включает все доступные целые количества товара. Взятки предлагаются кратно 5 alashi и на весь остаток денег; ставки кратно 1 alashi и на весь остаток. После ставки можно выполнить основное действие. Обмен валюты и бартер в интерфейс этого опыта не входят; также недоступны торговля голосами, ручной выбор режима границы и покупка инсайда. Это полные партии через интерфейс evalgame, а не проверка всего пространства команд живой арены.

observed. До основной серии прошли шесть тестов интерфейса и runner. Все 12 контрольных партий встроенных ботов после расширения наблюдения совпали с исходными результатами. Диагностические пилоты исключены из основной выборки. Первый пилот выявил недопустимый индекс; в меню добавлены явные номера. Второй пилот остановлен защитой записи при временном падении свободного места. Эти попытки сохранены отдельно. После освобождения кэша сборки пилот завершил шесть раундов: 21 решение, из них 18 запросов модели, без недопустимых индексов.

source_defined. Модель возвращает номер кандидата. Неверный индекс не заменяется действием по смыслу объяснения. Допускается одна коррекция формата с теми же состоянием и кандидатами, без стратегической подсказки; число попыток API на решение не превышает трёх, включая сетевые повторы. Ошибки и исправления записываются. Более слабая модель и подставной pass не используются. Единственный допустимый кандидат выбирается автоматически с меткой forced.

## Ограничения

not_validated. Причинный механизм названий и перенос на другие модели не установлены. Исследуется один псевдоним модели, русский язык и фиксированный состав соперников. Названия меняют длину текста и токенизацию; этот опыт не раскрывает внутренний механизм модели. Правила живой арены и эффект сетевой задержки отдельно не проверяются.

## Файлы

- `protocol.json`: зафиксированные условия и расписание партий; хеши исходников.
- `run_experiment.py`: сборщик с отдельной историей каждой партии.
- `snapshot/`: исполнявшийся снимок исходников; `source-base.json` фиксирует версию правил.
- `engine-validation.json` и `engine-baseline-games.json`: проверки интерфейса и контрольные партии.
- `cases/`: все 72 партии, исходные запросы API и ответы, трассы решений и итоговые GameRecord.
- `results.json`: основной расчёт и все группы seed; `report.html`: интерактивный просмотр партий.
- `replay-validation.json`, `settlement-validation.json`, `integrity-validation.json`: окончательные проверки.
- `artifact-manifest.json`: хеши переносимого архива и проверка отсутствия ключа.
- `interruptions/`: резервная копия исходного прерванного состояния; `resume_campaign.py`: отдельное продолжение.
- `pilot-fullgame*/`: отдельная диагностика, исключённая из основной оценки.

Лимит серии: 2200 вызовов API, 15 миллионов входных токенов и 3 миллиона выходных. Предел активного времени сбора 7200 секунд, с явно записанной технической поправкой о перерыве. Квота подключённой подписки проверена до запуска; покупка кредитов не выполняется.

## Воспроизведение сборки

Для сборки нужен Rust 1.89.0. Из корня этой папки:

```bash
CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_DEV_INCREMENTAL=false cargo +1.89.0 build --locked --manifest-path snapshot/arena/Cargo.toml --bin evalgame --target-dir /tmp/alashi-fullgames-build
mkdir -p bin
cp /tmp/alashi-fullgames-build/debug/evalgame bin/evalgame
```

Сборщик читает `ALASHI_ZAI_CODING_KEY` либо существующий профиль ZAI Coding Plan в OpenCode. Ключи и заголовки авторизации не записываются в результаты. Сбор использует подписку модели; новый опыт требует отдельной папки и нового протокола. Исторические ответы не перезаписываются.

## Пересчёт без запросов модели

```bash
python3 replay.py
python3 check_settlement.py
python3 verify_integrity.py
python3 analyze.py
```

После новой сборки бинарный файл может отличаться по хешу. Только для офлайн-replay допускается явный флаг `python3 replay.py --allow-rebuilt-binary`: исходные хеши снимка и точное равенство всех GameRecord всё равно проверяются, отличие бинарного файла фиксируется в результате. Коллектор такой флаг не использует. Для одной арифметики выплат и анализа бинарный файл не требуется. Повторный `run` не нужен и исторические ответы не перезаписывает.

Полный CI действующей арены и ончейн-исполнение не запускались. Продуктовый код и правила не менялись; проверен исследовательский снимок и его записи.
