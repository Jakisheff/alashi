source_defined. Завершённые партии не запускаются повторно. Частичные партии воспроизводятся по принятым решениям, с точным сравнением наблюдений и связей с исходными ответами. Первая сохранённая допустимая команда используется без повторной генерации. Запрос без сохранённого ответа расходует попытку; новое обращение может занять только следующую свободную попытку. Предел трёх попыток на решение сохраняется. Два запроса без ответа считаются исходами неизвестной стоимости; выдуманная оценка токенов им не присваивается.

source_defined. Восстановление продолжает оставшиеся задания в исходном порядке, четыре работника. Общие лимиты вызовов и известных токенов сохраняются. Исходный предел 7200 секунд применяется к активному времени двух сегментов, включая 1294,11 секунды первого процесса. Это отклонение от непрерывного запуска: календарный перерыв исключён из этого бюджета. Никакие seed не заменяются. Итоговая статистика по полным группам и правило минимум шести полных групп остаются прежними.
