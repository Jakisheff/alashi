# Названия ролей и решения агента alashi

observed. В опыте 19 октября 2026 года убедительный эффект замены названий не обнаружен: расхождение между исходной и нейтральной версиями превышает среднее расхождение повторов на 1,16 процентного пункта, односторонний перестановочный p = 0,2826. Это не доказывает отсутствие эффекта.

Архив содержит 288 записей запросов к GLM-4.5-Flash: 282 допустимых ответа, четыре ошибки API и два потерянных ответа после сбоя записи. Проверялись отдельные состояния последнего раунда с заданным продолжением. Исторические персоны агентов и их память в этот опыт не входили.

## Устройство опыта

12 состояний → 4 сочетания названий → 6 отдельных запросов на сочетание → выбранное действие → выплата по сохранённой версии правил.

| Код | Название роли X | Название участника |
|---|---|---|
| PP | президент | фракция |
| NP | держатель X | фракция |
| PN | президент | элемент |
| NN | держатель X | элемент |

observed. Правила и все числа совпадают после обратной замены названий. Порядок допустимых действий одинаков внутри каждого состояния. У запросов отдельные контексты; порядок отправки перемешан. Температура 0,7, top_p 0,95, предел ответа 256 токенов.

source_defined. Основная метрика и 10000 перестановок для сравнения PP с NN зафиксированы в [protocol.json](protocol.json) до первого экспериментального ответа. Проверка чувствительности к техническим пропускам добавлена после сбоев; она не заменяет основной тест.

## Результат

| Сравнение | Доля пар с разными действиями |
|---|---:|
| Повторы PP | 43,06% |
| Повторы NN | 32,22% |
| PP против NN | 38,80% |

observed. Среднее повторное расхождение равно 37,64%. Разница с PP против NN составляет 1,16 процентного пункта. Полный расчёт находится в [results.json](results.json), распределения для каждого состояния в [report.html](report.html).

observed. В состоянии A1 версия PP шесть раз выбирала передачу 10 alashi участнику 1. Версия NN три раза выбирала ту же передачу и три раза производство. По заданному продолжению передача даёт выплату 55 alashi, производство 50 alashi. Это отдельное наблюдение, а не подтверждение причины различия.

not_validated. Другие модели и полные партии не проверены. Слова «держатель X» и «элемент» тоже могут вызывать ассоциации. Вместе с названиями меняются длина текста и токенизация. Опыт измеряет различия ответов; он не устанавливает внутренний механизм модели.

## Исходные данные

- [protocol.json](protocol.json), [prompts.json](prompts.json) и [schedule.json](schedule.json): метод, точные сообщения и порядок запросов.
- [responses.jsonl](responses.jsonl): все 288 записей, включая технические пропуски.
- [resume-amendment.json](resume-amendment.json) и [responses-before-resume.jsonl](responses-before-resume.jsonl): описание перерыва после отправки запросов 125 и 126 и сохранённые к этому моменту 124 записи. Потерянные ответы не генерировались повторно.
- [fixtures.json](fixtures.json), [scenarios.json](scenarios.json) и [validation.json](validation.json): состояния с выплатами и результаты проверок.
- [experiment.py](experiment.py), [resume.py](resume.py) и [resume-run-function.py](resume-run-function.py): исходный сборщик и возобновление серии.
- [pilot.json](pilot.json) и [pilot.py](pilot.py): предварительная проверка API, исключённая из основной выборки.
- [artifact-hashes.json](artifact-hashes.json): контрольные суммы файлов исходного архива.

Снимок правил в [rules/](rules/) совпадает с локальной версией alashi на коммите `929e4e519df32501e35b8b999eaf3031f508e092`. Это версия опыта, а не заявление о текущих правилах `main`. Исходные файлы скопированы без правок, чтобы сохранить контрольные суммы. Архивное поле `REPO` в сборщике содержит путь ноутбука автора; секретных значений в пакете нет.

## Повторный расчёт без запросов к модели

Из корня репозитория, Python 3:

```bash
cd docs/research/label-experiment-20261019
python3 verify.py
python3 analyze.py
```

observed. `verify.py` независимо проверяет арифметику всех 52 ветвей. `analyze.py` сверяет зафиксированные входные хеши и порядок 288 записей, затем перезаписывает `results.json` и `report.html`. Эти команды не используют API и не обращаются к арене.

Для повторного выполнения снимка движка нужен Rust 1.89 и зависимости из `engine/Cargo.lock`:

```bash
cargo +1.89.0 run --locked --manifest-path engine/Cargo.toml > /tmp/alashi-label-scenarios.json
```

Сравните полученный JSON с `scenarios.json`. Для новой серии ответов создайте отдельную копию сборщика, исправьте путь `REPO` и зафиксируйте новый протокол. Исходный архив сохраняет выполненный опыт; ответы API при новом запуске могут отличаться.
