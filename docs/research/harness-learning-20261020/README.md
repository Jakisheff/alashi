# Самостоятельная находка и изменение обвязки alashi

Статус: target. Отдельная сессия GLM-5.3 исследует старые числовые журналы, формулирует проверяемую закономерность и пишет memory.md и helper.py. После диагностических партий она получает право на одну окончательную редакцию. Зафиксированная версия проверяется на новых партиях. Веса модели и игровые правила сохраняются.

48 старых партий → самостоятельный анализ → начальная обвязка → 18 диагностических партий → окончательная обвязка → публичная фиксация → 108 новых партий.

source_defined. В корпус входят все 48 партий A0/A1 предыдущего опыта. Выбор не зависит от выплаты. Из данных убраны объяснения прежних агентов и человеческие отчёты; также удалены seed и обозначения экспериментальных вариантов. Модель получает только числовые журналы через ограниченные операции анализа. История текущего чата ей не передаётся. Пространство поиска не задаёт конкретную стратегию.

source_defined. Общие правила описывают доступные действия и итоговую выплату. Для аукциона дан обычный контракт ставки и возврата без объяснения ранее найденной производной закономерности. Эти правила одинаковы для всех вариантов. Самостоятельное обнаружение связи в данных не означает новизну этой связи для всех участников проекта.

source_defined. Исполняемая правка ограничена дополнением контекста. Чистая функция augment получает только публичное состояние текущей партии и собственную историю. Доступ к файлам и сети ей не предоставляется. Вычисленные признаки не заменяют исходное состояние и не выполняют действия. Все варианты используют одинаковое законное меню, одну модель и одинаковый предел ответа на решение.

source_defined. Итоговые варианты A0 и A1 являются независимыми повторами исходной обвязки. H использует зафиксированную моделью версию. Двенадцать новых seed, три места и три варианта дают 108 полных шестираундовых партий. Шесть seed используют знакомых greedy/tactical, остальные random/genome. Все seed отличаются от корпуса и диагностической серии.

source_defined. Первичная метрика: выплата H минус среднее A0/A1, сначала по трём местам, затем по seed. Проверка: точная двусторонняя перестановка вариантов внутри seed и 95% bootstrap-интервал по seed. В вывод входят только полные группы по девять партий; требуется минимум восемь групп. Все ошибки остаются в отчёте, замены seed не допускаются.

not_validated. Эффект обвязки, корректность найденного механизма и перенос на новых соперников до завершения проверки не установлены. Это отдельный опыт по мотивам подхода Harness², а не воспроизведение его модельных бенчмарков.

Условия и ограничения: protocol.json. Данные: training.json; происхождение: training-manifest.json. Сырые обращения модели сохраняются до применения действий. Секреты и заголовки авторизации в архив не входят. Правила и бинарный файл совпадают с исследовательским снимком предыдущего опыта; продуктивная арена не меняется.
