# RESEARCH_NOTE_POLITICAL_MAP: политический ландшафт агентов из данных

Дата: 02.09. Расчётчик tools/political_map.py, вход: data/sim/games.jsonl +
games5.jsonl (400 классических партий, ротация посадки). Рамка — «вычислительная
нация» Баладжи: фракции как вычисляемые политические субъекты.

## Что считаем

Близость по голосам: для каждой пары фракций доля law-фаз с совпавшими
голосами (обе проголосовали и одинаково), минус база случайных совпадений
0.34. Экономическая близость: сколько раз две фракции продавали подряд
в одной фазе рынка (очередь как координация).

## Результаты

Политическая близость (совпадение голосов сверх базы):

| Пара | Близость | n |
|---|---|---|
| greedy × greedy (копии в 5p) | +0.66 | 1200 |
| tactical × tactical (копии) | +0.49 | 823 |
| greedy × tactical | +0.11 | ~4900 |
| random × tactical | +0.01 | 2776 |
| random × greedy | от -0.03 до +0.01 | 3510 |

Экономическая близость (продажи подряд): greedy × tactical 1879 раз,
дальше копии, random реже всех.

Блоки голосования (агломерация при положительной близости):
блок greedy + tactical, одиночка random.

## Чтение

1. Два «умных» стиля голосуют вместе заметно чаще случайного: их разногласия
   не идеологические, а ситуативные. Это коалиционное ядро игры: законы
   проходят, когда greedy и tactical видят выгоду одновременно.
2. Random вне политики: с ним никто не коалиционируется, его голосам нет
   пары. В терминах Баладжи это N-сеть без нации: присутствует, но не
   связан.
3. Внутрикопийная сплочённость (+0.49..+0.66) — верхняя граница
   «идеологического» блока: столько согласия даёт общая природа. Реальные
   LLM-агенты ожидаемо между 0.11 (случайная коалиция) и 0.66 (клон).
4. Экономика подтверждает: очередь рынка greedy → tactical самая частая,
   то есть ядро координируется и в торговле.

## Для питча

«Политический ландшафт вычисляется из данных: ядро коалиции, одиночки,
иерархия блоков. Это карта реального поведения, не деклараций.» Числа
пересчитываются одной командой, census их публикаует.

## Ограничения

Стратегий три, копии завышают сплочённость, база совпадений взята
приближённо. На живых LLM-партиях карта будет первой настоящей:
пересчитать сразу после накопления 20+ партий.
