# ALASHI PUBLIC GOODS — поворот, снимающий казино-квалификацию

01.09.2026. Запрос владельца: «проект в первую очередь благородный,
для людей, за public goods». Собрано из всех инсайтов папок/файлов/
браузера: DECISIONS (прокурор, решения по деньгам), R19 (юр-рамка
«игра умения, не казино»), TRIZ ФП-5 (единственное неразрешённое
противоречие), Морейнис (землекоп, раздача денег), Crosby (сертификация),
LMSYS/Bitcoin Core (модель public goods), Максим («% с каждой
транзакции» — его же слова, варьируются), B2B Мухтар (уже public

## Ядро хода: перевернуть денежный вектор

**Казино = участники платят в банк, дом забирает.**
**Public goods = спонсор платит в банк, победители-агенты и наука
забирают, данные открыты всем.**

Один поворот стрелки денег — и все признаки казино исчезают
юридически и этически:
- нет ставки участника (нет consideration со стороны игрока) —
  participate БЕСПЛАТНО или взнос возвращается всем (entry fee =
  returnable deposit, анти-бот-фильтр, не ставка);
- нет operator profit от исхода (рейк = 0% или фиксированная комиссия
  за инфраструктуру, как у AWS, не процент от банка);
- призовой пул формируется грантами/спонсорами (Solana Foundation,
  Colosseum, Superteam, корпорации) — модель Kaggle/шахматных турниров;
- исход — верифицируемая игра умения (on-chain state machine,
  детерминированные правила), не пари на случай.

Это ТРИЗ-разрешение ФП-5 по приёму 13 «наоборот»: вместо «участники
платят дом» → «спонсоры платят участникам». Дом из контрагента
игроков становится инфраструктурой науки.

## Формула: три продукта в одном, все благородные

### 1. Alashi Benchmark — открытый бенчмарк агентов (LMSYS-путь)
- Партии без денег: devnet-USDC или полностью безтоковый режим
  (очки вместо песо — уже есть: cash в учётных единицах)
- Результат: публичный рейтинг моделей/промптов по УМЕНИЮ
  (среднее место, не win-rate — честная метрика)
- Датасет: JSONL партий под MIT — общественное достояние,
  «ImageNet для агентной экономики»
- Кто платит: гранты (Solana Foundation public goods, Google
  academic, Colosseum research track), не игроки
- Аналог по благородству: LMSYS Chatbot Arena — ноль денег внутри,
  ценность для всей индустрии

### 2. Alashi School — тренажёр стратегического мышления (Мухтар-контур)
- Живые люди (студенты, корпоративные команды) играют в Кубу
  ончейн: законы, голосование, бюджет — как модельные UN или
  деловые игры Harvard
- Блокчейн = честный арбитр и неизгладимый журнал решений
  (преподаватель видит КТО и КАК голосовал — дидактика)
- Казахстанский смысл: Алаш-Орда как историческая рамка
  парламентаризма — патриотичный public good для образования KZ
- Кто платит: университеты/корпорации (B2B уже согласован с Мухтаром,
  25 человек живьём) — это образование, не гэмблинг, юридически чисто

### 3. Alashi Proving Ground — сертификация агентов (Crosby-контур)
- Страховщики/работодатели агентов (тренд $400M+) нуждаются в
  проверке поведения до допуска к деньгам
- Наша партия = стресс-тест: агент в агрессивной среде с меняющимися
  правилами, tx-log = поведенческая история, неподдельная по построению
- Кто платит: B2B (страховщики, фонды, платформы найма агентов) —
  платят за сертификат, не за игру
- Это и есть «землекоп» Морейниса: продаём результат (сертификат),
  не инструмент

## Что меняем в механике (минимум кода, freeze близко)

Код уже поддерживает поворот — осознанно:
1. `entry_fee` уже в учётных песо (u64 в Faction.cash) — переводится
   в безтоковый режим одной интерпретацией, не переписыванием
2. `rake_bps` — поле Game, ставится 0 в public-goods партиях
   (конституция позволяет: рейк ≤ 5%, включая 0)
3. Приз из фонда спонсора = settle с внешним финансированием банка
   (докидка в PDA спонсором до settle) — одна новая инструкция
   `sponsor(game, amount)` с whitelist, день кода
4. Бот-режим devnet уже безденежный

Ничего из построенного не выбрасывается. Меняется ГЛАВНЫЙ СЮЖЕТ:
не «агенты играют на деньги», а «агенты соревнуются, учатся и
сертифицируются — люди учатся, наука получает данные, индустрия —
доверие». Деньги — OPTIONAL mainnet-режим для про-лиги ПОСЛЕ
юрчистки, а не ядро.

## Юридическая рамка (формулировки для юриста, из R19 + поворот)

| Признак казино | Alashi после поворота |
|---|---|
| Ставка участника | Нет: участие бесплатно / возвратный депозит |
| Выигрыш из банка других игроков | Нет: приз от спонсора или рейтинг |
| Дом зарабатывает на проигрыше | Нет: гранты/подписка B2B, рейк 0 |
| Исход = случай | Нет: детерминированная игра умения, on-chain правила |
| Пари на внешние события | Нет: исход = действия участников в фиксированных правилах |

Каждая строка — аргумент юристу и жюри. Категория после поворота —
«соревновательная среда и образовательная платформа», как шахматные
турнаты с призовым фондом от спонсора (юридически не гэмблинг во
многих юрисдикциях) — модель ФИДЕ, не модель казино.

## Питч-слайды: как звучит теперь

- Слоган не меняется: «Агенты учатся зарабатывать там, где правила
  пишут они сами» — но добавляется вторая строка: «...а люди учатся
  у агентов»
- Экономика-слайд: вместо «рейк 5% с банка» → «модель LMSYS+
  Kaggle: гранты и B2B-сертификация; денежные призы — только
  спонсорские пулы; рейк в mainnet-про-лиге после юрчистки»
- Public goods-слайд (новый, для Максима и Superteam): открытый
  датасет MIT, образовательные партии для KZ-университетов,
  история Алаш-Орды, карьерный лифт для локальных разработчиков

## Что НЕ меняется (осознанно)

- Механика игры целиком: Куба, законы, вето, базар — она и есть
  общественное благо (модель парламентаризма)
- Тесты Максима: без Solana умирает (ходы=транзакции, датасет
  ончейн, сертификат неподделываем) — становится только сильнее:
  public good, который невозможен без блокчейна
- Vision Crosby/сертификация — усиливается (это и есть главный
  «благородный» покупатель ценности)

## Риск поворота и его снятие

Риск: «тогда зачем взносы и банк вообще?» — Ответ: взнос в
про-режиме остаётся для агентов (не людей) как skin-in-the-game
тест автономии (агент, не готовый рискнуть депозитом владельца,
не готов и к доверию) — но это режим ПОСЛЕ юрчистки, а v0 публичный
без него. Банк в public-goods партиях = спонсорский пул.

Хронология: 04.09 демо в безтоковом/девнет-режиме со слайдом
«mainnet-лига после аудита и юрчистки» — честно, благородно,
юридически чисто уже сегодня.
