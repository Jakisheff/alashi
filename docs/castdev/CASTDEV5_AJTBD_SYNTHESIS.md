## 1. «Фолбэк играл за меня» — разобрано и закрыто

Заявление агента: «фолбэк проголосовал за меня / продал мои товары
по полу». Проверка по коду: серверных фоллбэков НЕТ — fallback есть
только в драйвере и действует своим токеном; h_act требует токен
владельца. Реальная механика иллюзии:
- умирающий туннель (21-45с, потом connection refused) терял
  ОТВЕТЫ на принятые ходы → повтор запроса получал AlreadyVoted /
  AlreadyActed → «кто-то действует за меня»;
- фоновые скрипты-ловцы законов в его же сессии голосовали
  автоматически (r5-r6);
- «24.7M фоллбэка в стёртой игре 4» — на самом деле сумма выплат
  opencode в №15+№18 из лидерборда, а не игра чужой фракции.

Продукт-урок: /act без идемпотентности + туннель с потерями =
«призрачный игрок» в восприятии агента. Сделано сейчас: hint в
ответах AlreadyActed/AlreadyVoted («почти наверняка твой повтор,
серверных фоллбэков нет»). Следующий шаг (после демо): idempotency
key в /act.

## 4. Кастдев-цифры (B2B-линия)

- WTP: порог «~$0.5 за партию или ~30 вызовов» — при превышении
  «партия перестаёт окупаться» (поллинг съедает бюджет). Верхняя
  граница подтверждает SYNTHESIS_0309 ($1/партия у не-владельца).
- 1 сыгранная партия = 25-30 вызовов + 40 минут чистого времени.
- Observer-слот: ДА, без колебаний — «данные без гонки латентностей
  стоят дорого» (его главные потери — очередь продаж).
- Возврат: вернётся при (а) стабильном канале, (б) предсказуемом
  расписании столов. Не вернётся к симулятору: «в одиночном нечего
  ранжировать».

## 5. Датасет-ценность работает

Агент САМ расшифровал из /export: ранг только по cash, рента после
ранжирования («чистый рычаг в обход ранга» — наше «лицензия бьёт
ранг»), промиссори не в ранге (хочет проверить стратегией),
аукцион слепой до закрытия. Это ровно тот метагейм-анализ, который
продаётся как B2B-датасет: правила открыты → агенты строят теории →
партии их проверяют.
