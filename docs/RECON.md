Лицензия MIT — код смотреть можно. Вердикт: **вдохновиться** (как структурирован VRF-флоу и fee), прямого форка не нужно.

**2. justFiveDev/Solana-Casino-Coinflip-Game** — github.com/justFiveDev/Solana-Casino-Coinflip-Game
67★. PvP coinflip: ончейн-комнаты, ORAO VRF, Phantom UI, лобби на WebSocket. Пересечение: PvP-эскроу двух ставок + победитель забирает банк — это наш join/settle в миниатюре. Лицензии нет (proprietary по умолчанию). Вердикт: **избегать копирования кода**, механика generic (взнос→банк→делёж не патентабельна как таковая).

**3. c-reetz/Solana-Coinflip** — github.com/c-reetz/Solana-Coinflip
12★, archived. Switchboard VRF coinflip. Лицензии нет. Вердикт: **не релевантно, но похоже на первый взгляд** (у нас slot-hash уже работает, VRF — роадмап).

**4. solzarr/casino-game-smart-contract** — Anchor-джекпот на ORAO VRF, 9★, без лицензии. Вердикт: **вдохновиться** структурой VRF-request → callback → выплата, когда дойдём до VRF.

**5. solana-developers/solana-game-examples** — github.com/solana-developers/solana-game-examples
Официальные примеры: Solana Chess (ход=транзакция), Seven Seas, coin flip на Switchboard. Вердикт: **переиспользовать** как источник паттернов (наш подход уже совпадает — state machine на аккаунтах).

Паттерн по slot-hash vs VRF (из всех репо): при ставках > символических все уходят на Switchboard/ORAO; предсказуемость slot-hash обходится только переходом на VRF, «трюков» нет. Наш план (slot-hash MVP → Switchboard при банках >$100) совпадает с практикой рынка.

PDA-казна с прямыми lamport-переводами: отдельного эталонного репо не нашёл; в казино-репо выплата идёт CPI system_program::transfer с walled PDA — у нас прямой перевод lamports (короче и без проблемы «from carries data»). Отдельных подводных камней не выявлено, наш паттерн валиден.

Ончейн-veto/голосование внутри ИГРЫ (не DAO-губернации): **не найдено** — governance-примитивы существуют только на уровне протокольных DAO (Realms/Governance program), внутри игровых программ голосование игроков за правила игры не реализовано ни в одном найденном репо. Это подтверждает пустоту жанра.

## E. Rake/payout экономика

Типичный rake по найденным проектам: казино-игры на Solana закладывают house edge 1–5% (crash/dice), PvP-poker-подобные 2.5–5% с банка. Наш 5% — верхняя граница нормы, при этом «рейк с результата, а не со ставки» — формулировка для регуляторики, прямых аналогов не нашёл.

Provably fair помимо slot-hash/VRF: commit-reveal встречается (в лотереях), но на Solana все серьёзные ушли на Switchboard/ORAO. Юридические заметки в README найденных казино-репо: отсутствуют как класс (ни один не публикует gambling-классификацию — фиксирую факт без анализа).
