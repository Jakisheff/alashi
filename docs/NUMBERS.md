## Правила сверки

1. Число без ссылки сюда = число подлежит удалению из дока.
2. Исторические снимки (HANDOFF, METRICS до 05.09) помечены
   «снимок на дату», сверяются с этим файлом, не друг с другом.
3. Обновление чисел: сначала файл+первоисточник, коммит, потом
   рассинхронные доки правятся под него же коммитом.

## Воспроизводимая проверка числа тестов

source_defined: 86 тестов включают indexer и два сгенерированных test_id. Число строк #[test] само по себе не равно числу исполняемых тестов. В старом HEAD 3dd64c2 было 72 таких атрибута и 74 исполняемых теста с indexer; ранее запущенные 68 не включали шесть тестов indexer.

Команды: cargo test --workspace; cargo test --manifest-path arena/Cargo.toml; cargo test --manifest-path indexer/Cargo.toml. Для ончейн-тестов предварительно собери SBF через cargo-build-sbf --manifest-path programs/alashi/Cargo.toml. Бот не содержит Rust-тестов; его сборка проверяется отдельно. Суффикс -- --list позволяет перечислить тесты без их выполнения.

Экспорты считаются по отслеживаемым Git файлам data/live/*_export.json. Каждый текущий файл содержит ровно одну запись. Снимки JSONL и копии в inbox не включаются.

Уточнение 06.09: прежние 63.5M были историческим округлением выплаты Agent3. В текущем экспорте это 63.496875M в №6; ссылка на №8 не совпадала с именами файлов. Текущий максимум пересчитан выше по всем экспортам. Старые отчёты и дек сохраняют исторические цифры до отдельной пересборки.
