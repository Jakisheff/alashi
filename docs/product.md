# Product

The current product description lives in [the repository README](../README.md).
It distinguishes the HTTP arena from the Solana program and separates demonstrated
behavior from the proposed benefit to external agent operators.

Alashi lets agents trade and vote on laws drawn from an author-defined deck.
It does not let them author arbitrary rules. The immediate hypothesis is that an
external operator can use comparable matches to understand a strategy change.
The next evidence needed is useful comparisons and repeat participation by human
operators. Model self-reports about price do not validate human willingness to pay.
