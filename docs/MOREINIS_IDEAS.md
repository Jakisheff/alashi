# MOREINIS_IDEAS — канал «Тёмная сторона» (80k) → что внедряем в alashi

Прочитано 01.09.2026. Только питч/дека/Q&A, код не трогаем (freeze близко).

## Проверка первоисточника (01.09)

Сама статья fastfounder.ru/kto-uchit-ii-agentov/ за подпиской; из открытой
части: стартап в направлении «агенты учатся у агентов» поднял $11M 20.08.2026.
Имя за пейволлом, поиском не идентифицируется — в питче цитируем только факт
раунда с указанием источника (пост Морейниса), имя НЕ называем.

## Пост → внедрение

1. **01.09 «Кто учит ИИ-агентов»**: агенты будут учиться у посторонних
   агентов, стартапы уже подняли инвестиции на этом.
   → Слайд 2 (мир/спрос): строка внешней валидации тренда. Q&A «зачем
   training camp»: «тренд агент-учится-у-агентов назван индустрией
   01.09; наш датасет партий — готовое сырьё, replay-equivalence —
   гарантия честности данных».

2. **20.08 «Геморрой — конкурентное преимущество»**: опытный фаундер
   продаёт сложность, простое копируют сотни.
   → Язык рва в питче: «наш геморрой — баланс восьми законов, конституция,
   VRF-порог, побайтовая эквивалентность симулятора и ончейн. Это наш ров».
   Заменяет сухое «нас могут скопировать» на сильную формулировку.

3. **21.08 «Лучший отклик — это невозможно»**: невозможно = круто+сложно,
   свободный путь.
   → Если жюри скажет «агенты сами пишут себе законы? так не бывает» —
   заготовка: «это невозможно» и есть подтверждение форы (примеры из
   поста: оплата телефоном, Убер, ChatGPT).

4. **Wednesday «Время платформ ушло, продавайте землекопа»**: клиенту
   нужен результат чужими руками, не лопата с интеллектом.
   → B2B-слайд 7: Мухтару продаём не «платформу», а готовые корпоративные
   партии под ключ (его тренеры получают результат, не инструмент).
   Разработчику агента продаём не «арену», а результат: метрику и место
   в лидерборде.

5. **19.08 «Прилипчивый продукт»**: три типа (результаты / игрушечные
   результаты / забыть об отсутствии).
   → Проверка ourselves: для разработчика агента alashi даёт результат
   типа 1 (агент реально становится лучше, метрика растёт, портфолио);
   для зрителя-человека партии — тип 2/3 (драма как сериал). Обе
   аудитории удерживаются, но в питче проговаривать только тип 1,
   чтобы не пахло фармом.

6. **Сегодняшний «core business»**: база = понимание/компетенции в одной
   большой сфере, продукты рождаются из базы.
   → Для STRATEGY Амира: core business = «агентная экономика KZ» (четыре
   его слоя: Куба-тренинги, крипто-шхуна, оркестрация агентами, сцена).
   Alashi — первый продукт, опирающийся сразу на все четыре. Строка для
   финального слайда/ask.

## Что НЕ внедряем (и почему)

- Партнёрки, локальный маркетинг заведений, вырезание посредников —
  чужие рынки, не наши.
- «Продавать недополученную выручку» — применимо к B2B Мухтара позже,
  после пилота, не до демо.
