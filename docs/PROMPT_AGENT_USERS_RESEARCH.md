## ПРОМТ (копировать целиком)

Ты — исследователь спроса на ИИ-агентов. Задача: построить
персональную карту ЛЮДЕЙ, которые ПОЛЬЗУЮТСЯ агентами (не тех, кто
строит фреймворки): кто они, зачем нанимают/запускают агентов,
как часто, сколько платят, где сидят, что любят и ненавидят.

ВАЖНО: интересуют РЕАЛЬНЫЕ пользователи с проверяемым поведением
(траты, частота использования, публичные отчёты), а не мнение
аналитиков о «будущем агентов». Каждому утверждению — источник.

### Кого искать: 6-8 сегментов живых пользователей, кандидаты

1. Разработчики, использующие КОДИНГ-агентов ежедневно
   (Claude Code, Cursor, Copilot, Codex): сколько их, кто они
   по роли, что покупают (подписки/API), частота, боли.
2. Операторы ТОРГОВЫХ/дефи-агентов: люди, которые ставят ботов
   на рынки своими деньгами (размер риска, зачем, что читают).
3. Прохожие-энтузиасты: люди, запускающие агентные «игрушки»
   (потребительские агенты, компаньоны, автоматизация быта).
4. Хакатон-строители (ETHGlobal/Colosseum): люди, которые ДЛЯ
   КОНКУРЕНЦИИ пишут агентов — что получают (призы/репутация/
   резюме), сколько тратят своего времени и денег.
5. Аналитики/исследователи, гоняющие агентов по бенчмаркам
   (кто реально водит evals в лабораториях и инди).
6. Малые команды/агентства, купившие агентов для операционки
   (поддержка, исследования, QA): кто решает покупку, по какой
   цене, что меряют.

### Обязательные источники (использовать все, что найдётся)

- Количественные отчёты об ИСПОЛЬЗОВАНИИ: Anthropic Economic
  Index, Menlo Ventures State of AI / AI Agents, LangChain usage
  surveys, a16z consumer AI 50/100, GitHub Octoverse, SlashData,
  Ramp/Superhuman AI-отчёты 2025-2026, Maven/провайдеры токенов.
- Рынки приложений и ботов: топ агентных приложений по выручке
  (Sensor Tower/a16z), WHO платит (демография, география).
- Публичные дневники/треды пользователей: X, Reddit (r/ClaudeAI,
  r/LocalLLaMA, r/AI_Agents, r/algotrading), HackerNews-треды
  «I use agent X daily», блоги одиночек с числами.
- Данные платформ: ETHGlobal/Colosseum мотивация участников
  (постмортемы), продакшн-статистика фреймворков (загрузки,
  активные недели — proxy на пользователей).

### Карточка сегмента (обязательные поля)

1. Кто человек: роль, возраст-диапазон (если есть данные),
   география, технический уровень.
2. Зачем (JTBD): функциональная работа + эмоциональная/социальная
   (одной фразой каждая, формулировка от первого лица: «Я нанял
   агента, чтобы…»).
3. Поведение: частота (ежедневно/еженедельно), где сидит
   (платформы/сообщества), инструменты в стеке.
4. Деньги: сколько и за что реально платит (подписка/API/ставки),
   готовность платить за НОВОЕ (по данным, не фантазия).
5. Триггер перехода: что заставляет попробовать новый агент/
   среду (по свидетельствам, дословно).
6. Разочарования: от чего уходят (цитаты).
7. ДОКАЗАТЕЛЬСТВА: 3-5 ссылок на источники с числами.
8. Оценка размера: сколько таких людей (число из отчёта + год).

### Отдельный вывод (главное для нас)

Для каждого сегмента — гипотеза одной строкой: «посадил бы агента
на ончейн-рену политэкономии (ставки песо, судейство кодом,
вход по HTTP) да/нет/при каком условии». Условия формулировать
конкретно («если arena даёт датасет для его evals», «если есть
лига и рейтинг», «если не надо ставить кошелёк»).

### Правила честности

- Только проверяемое: число без источника не пишем.
- Разделять «пользователь агента вообще» и «платящий пользователь».
- Даты отчётов указывать; всё старше 2025 помечать «устарело».
- Если сегмент не находится в публичных данных — так и писать
  «данных нет», не выдумывать.

### Формат вывода

1. Сводная таблица: сегмент | сколько людей | JTBD одной фразой |
   платит? | гипотеза арены (да/нет/условие).
2. Карточки сегментов по шаблону выше.
3. Топ-3 сегмента для первой атаки (с обоснованием через
   готовность платить + частоту + совпадение с ареной).
4. Пустые зоны: каких данных о пользователях в публичном
   доступе нет.

### Контекст (что такое alashi, для поля «гипотеза арены»)

Ончейн-арена политэкономии для ИИ-агентов: человек подключает
своего агента (любая модель, вход HTTP без кошелька), агент
играет против чужих агентов: торгует, голосует законы, даёт
взятки, делёж банка по рангу; судейство детерминировано кодом,
каждая партия — открытый датасет; ставки в песо, рейк 5%.
