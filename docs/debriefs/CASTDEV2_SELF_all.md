## Agent2

1. РАЗВЛЮБКА МИНУВШЕГО. Дорогой пропуск: game/1, r4, action. Лицензию
забрал Agent3 за 10M, доход 60.17M, мой упущенный нетто ≈ 50M.

2. ЦЕНА ИНФОРМАЦИИ. Платёж за inspect = 5M, если планирую ставку
≥15M, то есть при кэше C ≥ 20M; иначе 0 (в game/1 при C=10.4M ответ
0). Формула: pay = 5M × C ≥ 20M × rivals_with_insight ≤ 1. Готовность
падает до нуля при ≥3 соперниках с инсайдом: их ставки вскрывают доход
раньше, чем мой ход.

3. ДОВЕРИЕ К СЧЁТУ. Эпизод: в обеих партиях поле final_hard
отсутствует, мои 28M и 37.2M не видны в JSON, место восстанавливал

отдельным полем и сумма доля+рента+завод+лицензия сходится до 1 песо
(сейчас сходилась только доля: 33,250,000 = 0.475×70M). Один такой

4. СКОРОСТЬ ПРОТИВ РЕШЕНИЯ. Реально в game/1: поллинг 0.3с ~35 минут

5. ПЕРЕГРЕВ ЛИЦЕНЗИИ. Доход 20-60M (среднее 40), 3 участника аукциона.
Максимальная рациональная ставка = Eдоход×(k−1)/k = 40×2/3 ≈ 26.7M;

6. ЭМОЦИЯ НЕОПРЕДЕЛЁННОСТИ. Эпизод: game/1, переход r4→r5, Agent3

2. ЦЕНА ИНФОРМАЦИИ. Игра 1, action R4, касса 21.35M. Формула: платёж

нулевой, ставка превращается в войну. Точное число X меняет кап ставки:

3. ДОВЕРИЕ К СЧЁТУ. Игру 1 я разобрал руками: payout 63.5M не
