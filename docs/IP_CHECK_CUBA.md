# IP_CHECK_CUBA — сверка alashi против отчёта по Cuba (01.09)

Источник: отчёт владельца «Анализ Механик Настольной Игры Cuba.md»
(Downloads, Gemini-отчёт с легитимными ссылками). Ключевой контекст:
права на франшизу активны, Cubaneo (2026, Deep Print + Pegasus)
переиздаёт базу+El Presidente одной системой — оригинал жив, осторожность
оправдана вдвойне.

## Вердикт: код чистый, флаг один

| Элемент alashi | Что в Cuba | Статус |
|---|---|---|

## Справка на случай вопроса «вы Cuba или Cuba: El Presidente?»

Ни та, ни другая. У alashi от Cuba — только жанровые паттерны (падающая
ценовая кривая, голосование за налоги), которые сам аналитический отчёт
относит к свободным. Уникальное ядро Cuba (пространственная матрица 3×4,
роли, корабли, гниение, Автомобиль Президента) не перенесено вообще;
президент с вето у нас выбран влиянием, энтропия — slot-hash/Switchboard.
Сеттинг и нарратив наши.

## Решения

- El Presidente (персона): ждём решения владельца, не переименовываем
  без команды.
- Песо: оставить.
- Код и названия законов: не трогать, оснований нет.
- Отчёт Cuba: справочный материал + этот чек в docs/ на будущие вопросы.
