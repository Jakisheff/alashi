# Alashi: прототипы Degenie

Амир ведёт проект напрямую с Codex с 16.10.2026. Исходники и результаты работы сохраняются в GitHub. Участие Ивана и Дины для продолжения работы не требуется.

## Текущий вариант: общая RTS-карта

[Два штаба и восемь Degenie](rts-overview/README.md) выполняют поручения параллельно. Часы среды продолжаются, пока сценарные клиенты принимают решения. Использованы исходные модули AgentEnv RTS; их происхождение и границы переноса описаны в [REUSE.md](rts-overview/REUSE.md).

Из корня репозитория:

```sh
python3 experiments/alashi-watch/rts-overview/runtime.py
```

Откройте http://127.0.0.1:8767/. Кнопка задержки Chief Б показывает, что выданные поручения продолжаются. Проверка без браузера:

```sh
python3 experiments/alashi-watch/rts-overview/check_runtime.py
```

observed: 16 проверок транспорта и порядка событий проходят. Модели LLM и основной runtime Alashi не подключены. Баланс от доставки отчёта не меняется. [Визуальная приёмка](rts-overview/ACCEPTANCE.md) остаётся открытой: частота кадров нестабильна, архитектура концепта не воспроизведена. Диагностические видео не доказывают плавность сцены.

## Предыдущие варианты

[Один цикл Degenie](degenie-cycle/README.md) содержит 28-секундное видео и редактируемую сцену Blender. В нём проверены контакты рук с планшетом, но Амир отклонил медленный темп и концентрацию камеры на одном работнике. Запуск плеера: `python3 experiments/alashi-watch/serve-preview.py`, адрес http://127.0.0.1:8766/.

[Макет с маркерами](README-dots.md) сохранён как история. Он не задаёт облик персонажей. REVIEW.md, STAGING.md и корневой RESULTS.json относятся к этому раннему проходу.

## Исходные материалы и состав

[Концепт Амира](source/alashi-two-sides-concept.png) задаёт визуальную цель. [Документ от 15 октября](source/ALASHI_SWARM_BATTLE_REPUTATION_2026-10-15.md) сохранён без изменений как исторический источник. Его поручения Ивану не действуют как текущий процесс. source/SHA256SUMS проверяет включённые исходные материалы; ORIGINAL-PACKET-SHA256SUMS сохраняет список всего исходного пакета, включая файлы вне этой папки.

В Git сохранены исходники прототипов вместе с моделями. Доказательства проверок включены в evidence/. Исключены установленные инструменты, полный клон внешнего Warcraft-репозитория, кеш кадров, резервные .blend1, временные логи и распакованная копия исходной модели. Лицензии используемых внешних модулей находятся в rts-overview/vendor. Исходный код модели сохранён в degenie-cycle/source-model.

Старые JSON-отчёты сохраняют время и локальные пути первоначальных запусков. Эти пути описывают происхождение артефактов; команды запуска используют путь текущего checkout. Публикация не запускает матч и не меняет действующий сайт.
