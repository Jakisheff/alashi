# Приёмка общей карты Degenie

Версия 16.10.2026. Общая карта реализована по исходному концепту Амира. Детальная декорация используется как слой сцены; Degenie отрисованы из исходного desk-genie.glb. Это 2.5D-представление с неподвижной камерой.

observed: восемь работников и два Chief находятся на одной карте. Первые шесть поручений выполняются параллельно. Проверяющие запускаются после доставки трёх отчётов своего штаба. Перелёт туда и обратно занимает 1,85 секунды; базовое поручение 4 секунды. Доставленный расчёт не меняет деньги.

В assets/degenie-complete-cycle.mp4 сохранён полный повтор. Каждый кадр строится по событиям завершённого цикла; FFmpeg получает явную частоту 30 кадров/с. Исходный снимок находится в evidence/full-cycle-source.json. Это повтор событий, а не измерение живой частоты кадров.

## Просмотр и соответствие концепту

observed: просмотрены начало цикла и одновременная работа двух штабов, затем возврат отчётов и обе приёмки. Ролик проигран в браузере с рабочим перемещением по времени. Положение Chief и центрального рынка соответствует концепту. Парламент остаётся ниже рынка; оба аналитических объекта читаются на общей карте. Камера не следует за одним исполнителем.

При просмотре раннего повтора А3 накладывался на озеленённую колонну. Его рабочая точка перенесена в свободный проход слева от парламента. Финальный ролик пересобран после этой правки.

| Принцип Лассетера | Проверка реализации |
| --- | --- |
| Squash and stretch | Корпус сохраняет размер. Видимый наклон не растягивает модель. |
| Timing | Короткий полёт отделён от работы. Первые шесть задач идут одновременно; проверка следует за отчётами. |
| Anticipation | Поворот к маршруту и сигнал приказа предшествуют полёту на 0,22 секунды. |
| Staging | Весь план виден одновременно, выбранный исполнитель увеличен в панели. Лица и идентификаторы разделены по высоте. |
| Follow through | Дым и исходная реакция сохранены в кадрах оригинальных клипов. |
| Pose to pose | Клипы idle и act взяты из исходной модели. Приёмку показывает её клип accepted. Ключевые стадии определяются событиями runtime. |
| Slow in and out | Плавное ускорение и торможение проверены на концах маршрута. |
| Arcs | Траектории проходят по кривым. Исправлен путь около колонны парламента. |
| Secondary action | Дым поддерживает движение; терминалы получают индикатор во время работы. |
| Exaggeration | Наклон и выбор исполнителя читаются на общей карте. Chief крупнее работника. |
| Appeal | Сохранён силуэт Degenie; окружение соответствует детализации концепта. Интерес нового зрителя не проверен. |

Переносимых физических предметов нет. Карточка над Degenie обозначает данные; она не выдаётся за удерживаемый планшет. Поэтому контакт ладони с предметом неприменим. Доставка в штаб подтверждается событием; реакция Chief следует после проверки.

## Численные проверки

observed: 18 проверок HTTP runtime прошли после обновления маршрутов. Проверены 808 точек траекторий, все стадии движения и reduced motion. Проверка повтора подтверждает, что будущий отчёт и приёмка не появляются раньше событий. Проверки экспорта покрывают порядок кадров и чужой идентификатор задания. Также проверены отмена и очистка незавершённого экспорта.

observed: npm run build и npm run check:animations прошли. Проверены 1532 кадра покупки, 827 старых клипов, 1099 кадров реакций и 5196 кадров сценариев. Эти проверки основного frontend дополняют проверки новой карты.

## Границы результата

observed: в этой среде пустая контрольная страница показывает около 17 кадров/с; живой план показывал 12-18 кадров/с. Это ограничение отделено от проверенного 30-кадрового повтора. Стабильные 30 кадров/с живой карты здесь не подтверждены.

not_validated: физический телефон и понимание новым зрителем. Реальные LLM и основной runtime Alashi не подключены. Выборы Chief сценарные; демонстрация проверяет визуализацию поручений. Проверка узкого окна сохранена отдельно в evidence/visual-checks.json.
