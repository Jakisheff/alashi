# Alashi: общая карта Degenie

Два Chief отправляют восемь Degenie на поручения. Первые шесть задач выполняются параллельно; проверяющие ждут доставленных отчётов. Вся карта остаётся в кадре. Окружение взято из концепта Амира, персонажи отрисованы из исходной модели Alashi.

[Полный цикл в движении](assets/degenie-complete-cycle.mp4) воспроизводится в 30 кадров/с. [Приёмка](ACCEPTANCE.md) объясняет проверки и ограничения. Первоначальный отчёт сохранён в ACCEPTANCE-early-20261016.md.

## Запуск

```sh
python3 runtime.py
```

Адрес: http://127.0.0.1:8767/. Кнопка «Готовый повтор» открывает сохранённый ролик. Кнопка «Новый цикл» запускает живое исполнение поручений. Задержка Chief Б не останавливает выданные задачи.

Для создания нового повтора нужен FFmpeg в PATH. Можно указать исполняемый файл через ALASHI_FFMPEG. После завершения цикла браузер передаёт точные кадры, FFmpeg собирает MP4. Временные JPEG удаляются; результаты остаются в exports/, которая исключена из Git. Сервер слушает только loopback. Эта функция не меняет игровые деньги.

## Проверки и ресурсы

```sh
python3 check_runtime.py
python3 check_export.py
node check_visual.mjs
```

Декорация assets/alashi-terrain.png подготовлена встроенным imagegen из исходного концепта; её происхождение сохранено в assets/terrain-provenance.json. Атлас assets/degenie-atlas.png собирается из оригинального GLB через tools/bake-sprites.html: восемь направлений и 24 кадра каждого клипа. Параметры находятся в assets/degenie-atlas.json.

map-layout.json задаёт свободные маршруты и темп. runtime.py исполняет задачи независимо от просмотра. map-motion.js проецирует эти же траектории; повтор показывает только уже наступившие события. Предметных контактов в сцене нет, карточка обозначает данные.

Сценарные клиенты используют исходный RemoteSession и Timeline из agentenv-wc3-plugin, commit 2376c509b6b5691858df2c9d4d1f79a7b1a877d1, Apache-2.0. Перенесённые файлы не изменены. [REUSE.md](REUSE.md) описывает границу переноса; лицензии находятся в vendor/.

Живые LLM и основной runtime Alashi не подключены. Баланс от отчёта остаётся 100. Частота сохранённого видео не является измерением живого браузера.
