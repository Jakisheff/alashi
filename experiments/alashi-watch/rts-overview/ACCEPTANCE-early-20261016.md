# Приёмка опыта повторного использования RTS

Статус: перенос команд и записи проверен. Общая 3D-карта реализована как прототип темпа. Полная визуальная приёмка не закрыта.

observed: все 16 проверок check_runtime.py прошли на окончательной версии runtime.py. При повторе обнаружена и исправлена гонка: событие приёмки теперь попадает в Timeline до ответа клиенту. Повторный успешный запуск из Git checkout занял 13,44 секунды. Синтаксис Python и JavaScript проверен. Изменений frontend проекта нет, его сборка и check:animations не запускались для отдельной исследовательской папки.

observed: исходный viewer AgentEnv открыл живые данные Alashi. В его журнале видны поручения обоих штабов, доставка отчётов и обе приёмки. Снимок DOM: evidence/reference-viewer.txt. Это второй потребитель формата, независимый от нашего scene.js.

observed: в браузере просмотрены общий план и движение восьми работников; доступны два Chief. Выбор Б4 меняет карточку и показывает согласование отчётов. Кнопка задержки Chief Б оставляет работу штаба А активной. Автоповтор очищает результаты предыдущего цикла. Для режима уменьшенного движения использованы конечные положения у штаба и терминала; финальная правка этого режима проверена синтаксически, повторный просмотр недоступен.

observed: при 390 и 320 CSS-пикселях горизонтального переполнения нет, кнопки около 44 пикселей высотой. На 320 пикселях main переходит в block. Крупный Degenie находится ниже карты. Скриншоты сохранены. Инструмент снимка применяет масштаб браузера иначе, чем DOM; снимок 390 не является точным доказательством физического размера телефона.

## Канон движения

| Принцип | Проверка и ограничение |
| --- | --- |
| Squash and stretch | Геометрия исходного Degenie сохранена; корпус не растягивается. |
| Timing | Поручение от 5,2 секунды; путь туда и обратно 2,88 секунды. Шесть поручений параллельны. |
| Anticipation | Перед полётом есть фаза команды 0,22 секунды и разворот. Читаемость взгляда на общей карте ограничена размером. |
| Staging | Общая камера сохраняет оба штаба и центральные объекты. Выбранный исполнитель имеет подпись и крупный план. |
| Follow through | Сохраняется исходный клип дыма. Ускорение маршрута не ускоряет все движения скелета одинаково. |
| Pose to pose | Использована исходная библиотека клипов GLB (idle / act / accepted). Новая работа со скелетом не создавалась. |
| Slow in and out | На концах полёта используется smoothstep. |
| Arcs | Маршрут имеет боковую дугу; направление корпуса меняется плавно. |
| Secondary action | Дым и мимика взяты из исходной модели. Карточка над головой обозначает данные. |
| Exaggeration | В полёте корпус наклоняется; выбранный робот выделен на карте. |
| Appeal | Характер Degenie сохранён. Архитектура концепта Амира пока представлена простыми объёмами; художественная готовность не подтверждена. |

Физических предметов в руках нет. Светящаяся карточка является индикатором, поэтому контакт ладони с ней не моделируется. Это зафиксированное отличие от предыдущего эпизода с планшетом.

## Незакрытые условия

observed: в этой среде наблюдались минимум 7 и максимум 24 кадра/с по rAF; это не стабильные 30 кадров/с. Повторный захват видео дал лишь 43 кадра за 14,44 секунды. Попытки записи сохранены как диагностические материалы, не как принятая демонстрация плавности. Неудачная функция записи убрана из интерфейса.

observed: при последнем обновлении браузерный инструмент завершился по тайм-ауту и сообщил, что IAB недоступен. Повторное открытие через Codex получило статус queued. Не утверждаем, что последняя визуальная проверка выполнена. Runtime доступен по HTTP и проходит проверки отдельно от браузера.

not_validated: привлекательность для новых зрителей, физический телефон, настоящие LLM, подключение к основному runtime Alashi и полноценный матч. Этот опыт обосновывает повторное использование модулей, но не доказывает художественную готовность Alashi.
