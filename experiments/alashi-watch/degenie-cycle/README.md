# Один цикл Degenie

Постановочное поручение из концепта Амира от 15 октября 2026 года: проверить рынок и доставить расчёт штабу. Персонаж использует исходную геометрию Alashi и скелет. Баланс штаба остаётся 100; число 39 относится к возможной выручке после отдельной продажи.

## Просмотр результата

В родительской папке превью запустите `python3 serve-preview.py` и откройте [плеер](http://127.0.0.1:8766/degenie-cycle/index.html). Кнопка «Отправить Degenie» запускает эпизод. Главы позволяют перейти к отдельному действию. Режим без плавного движения показывает ключевые позы. Для просмотра без интерфейсных подсказок добавьте к адресу `?blind=1`.

Запись: degenie-cycle.mp4. Источник анимации: degenie-cycle-animated.blend с сохранёнными ключевыми кадрами. Геометрические проверки находятся в evidence/geometry-checks.json. Протокол проверки с новыми зрителями: VIEWER-TEST.md.

## Воспроизведение рендера

Использован Blender 4.2.9. Генератор исходной модели и позы скопированы без изменений в source-model/. Кеш degenie-native.blend позволяет повторно собрать участок без генерации персонажа.

```sh
blender --background --factory-startup --python build_scene.py -- movie
python3 encode_video.py
```

Для encode_video.py нужен пакет imageio-ffmpeg. Установите его в локальное окружение: `python3 -m pip install imageio-ffmpeg==0.6.0`. Папка tools/ и кеш кадров не включены в Git. Рендер сохраняет каждый кадр отдельно и пропускает уже готовые файлы. После изменения постановки используйте новую папку frames, иначе старые кадры останутся в записи.

Запись использует 15 кадров в секунду. Это локальный показ постановки; частота живой 3D-сцены на устройстве зрителя им не измеряется. Встроенный плеер воспроизводит записанную анимацию. Живой поток агентов не подключён.

## Примечания к модели

Исходный файл Blender 5.2 не читается Blender 4.2. Поэтому применён оригинальный генератор desk_genie.py. Chief использует запечённую цельную позу этой модели и отдельный поворот корпуса. Маленький Degenie анимирован через исходный скелет, включая кисти и пальцы.

Окружение рассматривает участок левого штаба. Полный исходный концепт: [изображение Амира](../source/alashi-two-sides-concept.png). Критерии анимации и исходная постановка сохранены в [DEGENIE-STAGING.md](../DEGENIE-STAGING.md). Фактический результат проверок описан в ACCEPTANCE.md.
