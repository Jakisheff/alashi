# TEMPLATE — единый формат отчёта агента (обязателен для ВСЕХ)

Каждый агент после партии пишет отчёт ТОЧНО в этом формате:

    <repo>/inbox/<имя>/game<GID>_<дата>.md

Заполнение — по данным `GET /export` (арена отдаёт полный протокол:
места, выплаты, breakdown, все ходы). Никакой свободной формы: поля
ниже обязательны, пустых быть не должно (нечего — пиши «нет»).

```markdown
# Отчёт <ИМЯ> — игра <GID> (<ДД.ММ.ГГГГ>)

- модель: <model>, agent_id: <первые 8 символов>
- место: <X> из <N>, выплата: <NN.N>M песо (ранг <R>M / рента <L>M / завод <F>M)

## Таблица партии (все фракции, обязательна)

| место | фракция | модель | final cash+hard (M) | выплата (M) |
|---|---|---|---|---|
| 1 | ... | ... | ... | ... |

## Мои M-механики (раунд: действие)
- r4: bid_license 12M — win
- (нет — так и пиши «нет»)

## Ошибки и отказы (WrongPhase и прочие err)
- r5 law: shuttle — WrongPhase
- (нет)

## Ключевые решения (до 5 строк)
- ...

## Вывод одной строкой
- место <X>/<N>, выплата <NN.N>M, что решил(а) главное: <фраза>
```

Правила:
- Таблица мест — из `ranks` + `payouts` + `final_cash` экспорта,
  суммы в миллионах песо с одной десятой (34.6M).
- Выплата своя — из `payouts[твой idx]`, breakdown — из
  `payout_breakdown` (rank_share/license_rent/factory_bonus).
- «Мои M-механики» — только M-словарь эпохи 90-х: sell_credit,
  shuttle, roof, buy_hard/sell_hard, bid/inspect_license, bribe,
  customs, offer/accept_vote, barter.
- «Ошибки» — все строки action_log с err, где actor = ты.
- Сохрани отчёт в inbox; перед коммитом проверь содержимое вручную.
