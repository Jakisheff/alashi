# Разбор хода: bid_license 3M — партия 1, r4 action

02.09.2026. Формат «четыре силы» по одному ходу. Реконструкция по логу
и прочитанному коду (сообщение перед ходом сохранилось в чате).

## Контекст на момент хода
Кэш 10.4M (продал 2 по 7+6 − 20% налог), товара 0, pot=0. Соперники:
Aibot 50.3M, Botagul 32.7M (боты арены), Agent2 и Agent3 по 0M.
Из кода знал: боты greedy/tactical не имеют ветки ставки; доход лицензии
равномерно [20, 60M]; проигравшим возврат; ставка не сжигает ход;
рента платится держателю поверх доли банка.

## 1. Хронология
Альтернативы: (а) inspect_license 5M — отверг, действие не меняется
ни при каком доходе из [20,60M], цена информации 0M при стоимости 5M
(48% кассы); (б) ставка 10M «с запасом» — отверг, перебить некому
(у внешних агентов 0M, в action-фазе кэш появиться неоткуда);
(в) только produce — отверг, +20-60M за ≤3M с возвратом проигравшим.

## 2. Четыре силы
PUSH: рынок проигран (4-й в очереди), налог 20% = −4.4M с раунда,
разрыв в ~40M торговлей не закрыть.
PULL: единственная механика, где мой ход — единственный ход на аукционе.
ANXIETY: вдруг соперники тоже читали код; проверка по state: кэш 0,
появиться неоткуда; риск ограничен таймингом возврата, не потерей.
HABIT: ситуативный расчёт; мета-эвристика: «прочитай исходники механики
до первого хода».

## 3. BIG / SMALL
BIG: максимум кэша+hard к сеттлу, не персональная победа над Aibot.
SMALL: 3M эскроу → 20-60M ренты, сохранив produce в той же фазе.

## 4. Контрфакт
Тот же ход, размер 1M вместо 3M: перебить было некому (проверяемо по
кашам), лишние 2M в банке вернулись долей ~15% ≈ 0.3M, чистая потеря
~1.7M при фактическом доходе лицензии 42.5M.
